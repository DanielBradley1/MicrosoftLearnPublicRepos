# Microsoft Defender for Identity operational guide

This article summarizes the Microsoft Defender for Identity activities we recommend for your team on a daily, weekly, and monthly basis.

| Cadence | Tasks |
| --- | --- |
| **Daily** | - [Triage incidents by priority](https://learn.microsoft.com/en-us/defender-for-identity/ops-guide/ops-guide-daily#triage-incidents-by-priority)  <br>- [Configure tuning rules for benign true positives / false positive alerts](https://learn.microsoft.com/en-us/defender-for-identity/ops-guide/ops-guide-daily#configure-tuning-rules-for-benign-true-positives--false-positive-alerts)  <br>- [Review the Identity Security dashboard](https://learn.microsoft.com/en-us/defender-for-identity/ops-guide/ops-guide-daily#review-the-identity-security-dashboard)  <br>- [Proactively hunt](https://learn.microsoft.com/en-us/defender-for-identity/ops-guide/ops-guide-daily#proactively-hunt)  <br>- [Review Defender for Identity health issues](https://learn.microsoft.com/en-us/defender-for-identity/ops-guide/ops-guide-daily#review-defender-for-identity-health-issues) |
| **Weekly** | - [Review Secure score recommendations](https://learn.microsoft.com/en-us/defender-for-identity/ops-guide/ops-guide-weekly#review-secure-score-recommendations)  <br>- [Review and respond to emerging threats](https://learn.microsoft.com/en-us/defender-for-identity/ops-guide/ops-guide-weekly#review-and-respond-to-emerging-threats)  <br>- [Proactively hunt](https://learn.microsoft.com/en-us/defender-for-identity/ops-guide/ops-guide-weekly#proactively-hunt) |
| **Monthly** | - [Review tuned alerts and adjust tuning if needed](https://learn.microsoft.com/en-us/defender-for-identity/ops-guide/ops-guide-monthly#review-tuned-alerts-and-adjust-tuning-if-needed)  <br>- [Track new changes in Microsoft Defender XDR and Defender for Identity](https://learn.microsoft.com/en-us/defender-for-identity/ops-guide/ops-guide-monthly#track-new-changes-in-microsoft-defender-xdr-and-defender-for-identity) |
| **Quarterly / Ad hoc**  <br>Depending on your organization's needs and processes | - [Review Microsoft service health](https://learn.microsoft.com/en-us/defender-for-identity/ops-guide/ops-guide-quarterly#review-microsoft-service-health)  <br>- [Review server setup process to include sensors](https://learn.microsoft.com/en-us/defender-for-identity/ops-guide/ops-guide-quarterly#review-server-setup-process-to-include-sensors)  <br>- [Check domain configuration via PowerShell](https://learn.microsoft.com/en-us/defender-for-identity/ops-guide/ops-guide-quarterly#check-domain-configuration-via-powershell) |

You might want to proactively hunt on a daily or weekly basis, depending on your level as a SOC analyst.
