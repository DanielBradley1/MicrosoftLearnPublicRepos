# Provide feedback on the Microsoft Defender for Endpoint client analyzer tool

If you have feedback or suggestions that would help us improve the Microsoft Defender for Endpoint client analyzer, use either of these options to submit feedback:

- In the [Microsoft Defender portal](https://security.microsoft.com), select **Feedback** at the top of the page, and then fill out the information in the **Submit feedback to Microsoft** flyout that opens:

  [![Screenshot of the Feedback icon at the top of the Microsoft Defender portal.](https://learn.microsoft.com/en-us/defender-endpoint/media/defender-portal-feedback.png)](https://learn.microsoft.com/en-us/defender-endpoint/media/defender-portal-feedback.png#lightbox)

  [![Screenshot of the Submit feedback to Microsoft flyout in the Microsoft Defender portal.](https://learn.microsoft.com/en-us/defender-endpoint/media/defender-portal-submit-feedback.png)](https://learn.microsoft.com/en-us/defender-endpoint/media/defender-portal-submit-feedback.png#lightbox)
- On the [centralized feedback platform for Microsoft Defender XDR and related services](https://aka.ms/M365Defender/Feedback), select **Send feedback**, and then fill out the information on the **Post public feedback** page that opens:

  [![Screenshot of the Post public feedback page from the Microsoft Defender XDR feedback page.](https://learn.microsoft.com/en-us/defender-endpoint/media/defender-feedback.png)](https://learn.microsoft.com/en-us/defender-endpoint/media/defender-feedback.png#lightbox)

Tip

Do you want to learn more? Engage with the Microsoft Security community in our Tech Community: [Microsoft Defender for Endpoint Tech Community](https://techcommunity.microsoft.com/t5/microsoft-defender-for-endpoint/bd-p/MicrosoftDefenderATP).
