# Viva Learning Activity report

The Viva Learning Activity report helps you understand the activity of your licensed Viva Learning users by looking at their interactions. It also helps you understand the type of features being used within the Learning App.

For general information about usage reports in the Microsoft 365 admin center, and to see a list of all available reports, see [Microsoft 365 admin center usage reports overview](https://learn.microsoft.com/en-us/microsoft-365/admin/activity-reports/activity-reports?view=o365-worldwide).

## View the Viva Learning Activity report in the Microsoft 365 admin center

For information about the roles needed to view usage reports, see "Before you begin" in [Microsoft 365 admin center usage reports overview](https://learn.microsoft.com/en-us/microsoft-365/admin/activity-reports/activity-reports?view=o365-worldwide#before-you-begin)

1. Go to the [Microsoft 365 admin center](https://go.microsoft.com/fwlink/p/?linkid=2024339).
2. In the navigation menu, select **Reports**. If you don't see **Reports**, select **Show all**, and then select **Reports**.
3. Select [Usage](https://go.microsoft.com/fwlink/p/?linkid=2074756).
4. On the **Usage** page, under **Reports**, select **Viva Learning**.

## Interpret the Viva Learning Activity report

To get a view into your users' Viva Learning activity, look at the **Active users** and **User activities** charts.

[![Screenshot of the Viva Learning usage report.](https://learn.microsoft.com/en-us/microsoft-365/media/viva-learning-charts.png?view=o365-worldwide)](https://learn.microsoft.com/en-us/microsoft-365/media/viva-learning-charts.png?view=o365-worldwide#lightbox)

- **Active users:** Shows the number of active users over time. For example, use it to find the number of active users in your organization on a specific day over the past 30 days.
- **User activities:** Shows the number of user activities, such as viewed featured content, learning tabs pinned, viewed learning objects, consumed learning objects, recommendations made, and bookmarks.

To export the report data into an Excel .csv file, select **Export**. This action exports the usage data of all users and enables you to do simple sorting, filtering, and searching for further analysis.
