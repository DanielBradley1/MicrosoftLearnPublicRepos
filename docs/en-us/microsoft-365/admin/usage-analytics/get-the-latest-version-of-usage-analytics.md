# Update to the latest version of Microsoft 365 usage analytics

The template app might be refreshed with new data or new visualizations several times per year. Your existing instance continues to work during the update. However, if you want the latest version, you need to create a new instance and apply your customizations to the new instance. For more information, see [Enable Microsoft 365 usage analytics](https://learn.microsoft.com/en-us/microsoft-365/admin/usage-analytics/enable-usage-analytics?view=o365-worldwide).
