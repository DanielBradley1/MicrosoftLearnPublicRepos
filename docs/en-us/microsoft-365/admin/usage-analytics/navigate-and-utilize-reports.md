# Navigate and utilize the reports in Microsoft 365 usage analytics

The dashboard provides you with a quick overview of the main usage and adoption metrics. By selecting the top-level metrics, you can access reports that provide more details and insights. Each report tab contains data visualizations specific to an aspect of usage and adoption for your organization. The data collected is explained in the title of each report. Additionally, a tile appears that contains further information about the visualizations on the report tab that you're viewing.

To get started with your reports, here are some tips:

- Use the left navigation tabs or on a related metric on the **Executive Summary** page to navigate to each top-level report.

  [![Screenshot of the navigation tabs on the left.](https://learn.microsoft.com/en-us/microsoft-365/media/navigate-usage-analytics1.png?view=o365-worldwide)](https://learn.microsoft.com/en-us/microsoft-365/media/navigate-usage-analytics1.png?view=o365-worldwide#lightbox)
- To navigate to different reports within a level, use the navigation tabs at the top of each top-level report.

  [![Screenshot of the navigation tabs at the top of each report.](https://learn.microsoft.com/en-us/microsoft-365/media/navigate-usage-analytics2.png?view=o365-worldwide)](https://learn.microsoft.com/en-us/microsoft-365/media/navigate-usage-analytics2.png?view=o365-worldwide#lightbox)
- Many reports contain a slicer where you can filter on the product, Microsoft Entra attribute, or activity that you want to view. These filters can be either single-select or multi-select.

  [![Screenshot of a slicer.](https://learn.microsoft.com/en-us/microsoft-365/media/navigate-usage-analytics3.png?view=o365-worldwide)](https://learn.microsoft.com/en-us/microsoft-365/media/navigate-usage-analytics3.png?view=o365-worldwide#lightbox)

  [![Screenshot of a slicer in a drop-down list.](https://learn.microsoft.com/en-us/microsoft-365/media/navigate-usage-analytics4.png?view=o365-worldwide)](https://learn.microsoft.com/en-us/microsoft-365/media/navigate-usage-analytics4.png?view=o365-worldwide#lightbox)

  Hover data points to view a call out that contains details.

  [![Screenshot of a hover example showing details in a callout.](https://learn.microsoft.com/en-us/microsoft-365/media/navigate-usage-analytics6.png?view=o365-worldwide)](https://learn.microsoft.com/en-us/microsoft-365/media/navigate-usage-analytics6.png?view=o365-worldwide#lightbox)

The user who instantiates the template app has the ability to customize the report to their needs. To customize the template app:

- Select **Edit report** at the top of the report.

  [![Screenshot of the Edit report option.](https://learn.microsoft.com/en-us/microsoft-365/media/navigate-usage-analytics7.png?view=o365-worldwide)](https://learn.microsoft.com/en-us/microsoft-365/media/navigate-usage-analytics7.png?view=o365-worldwide#lightbox)
- Create your own visuals by using the underlying [datasets](https://learn.microsoft.com/en-us/microsoft-365/admin/usage-analytics/usage-analytics-data-model?view=o365-worldwide).
- Use Power BI Desktop to bring in your own data sources.

To share your reports, just select the share button ![](https://learn.microsoft.com/en-us/microsoft-365/media/dbb0569d-2013-4f9d-ab9d-d01b09631b92.png?view=o365-worldwide) at the top of the page.

To learn how to customize the reports, see [Customizing the reports in Microsoft 365 usage analytics](https://learn.microsoft.com/en-us/microsoft-365/admin/usage-analytics/customize-reports?view=o365-worldwide).
