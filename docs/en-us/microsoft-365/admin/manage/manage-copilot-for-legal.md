# Manage Copilot for legal

Microsoft offers a set of legal plugins that match legal professionals’ real-life workflows. Armed with these capabilities, Copilot can help legal professionals understand, summarize, draft, redline, review legal documents and more.

Two legal plugins are available: one for Copilot in Word and one for Copilot Cowork. Each is managed differently.

## Managing access

### Legal plugin for Copilot in Word

Within Word desktop, the legal plugin is enabled for all M365 Copilot commercial subscribers by default; when enabled Copilot can use legal skills to complete legal tasks in Word.

Access to the plugin can be governed via the Microsoft 365 Apps admin center. Tenant admins can control access by creating a policy configuration in the Policy Management tool. The policy name is "Legal Skills in M365 Copilot in Word".

### Legal plugin for Copilot Cowork

Within Cowork, end users must add the legal plugin in Cowork; when added, Copilot can use legal skills to complete legal tasks in Cowork.

Access to the plugin can be governed via the Microsoft 365 admin center. Tenant admins can control access via the Agent Tools page. The plugin name is "Legal for Cowork".
