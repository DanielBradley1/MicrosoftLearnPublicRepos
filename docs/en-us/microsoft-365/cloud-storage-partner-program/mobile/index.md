# Use the WOPI protocol to integrate with Microsoft 365 for mobile

You can use the Web Application Open Platform Interface \(WOPI\) protocol to integrate Microsoft 365 for mobile with your application. The WOPI protocol enables Microsoft 365 for mobile to access and change files that are stored in your service.

To integrate your application with Microsoft 365 for mobile, do the following:

1. Be a member of the Office 365 - Cloud Storage Partner Program. Currently, integration with Microsoft 365 for mobile using WOPI is available to cloud storage partners. Learn more about the program, as well as how to apply, at [https://developer.microsoft.com/office/cloud-storage-partner-program](https://developer.microsoft.com/office/cloud-storage-partner-program).
2. Implement the WOPI protocol - a set of REST endpoints that expose information about the documents that you want to view or edit in Microsoft 365 for mobile. The set of supported WOPI operations is described in [WOPI implementation requirements for mobile integration](https://learn.microsoft.com/en-us/microsoft-365/cloud-storage-partner-program/mobile/wopi-requirements).
3. Provide the required on-boarding information as described in the [Onboarding information](https://learn.microsoft.com/en-us/microsoft-365/cloud-storage-partner-program/mobile/onboarding/onboarding).
