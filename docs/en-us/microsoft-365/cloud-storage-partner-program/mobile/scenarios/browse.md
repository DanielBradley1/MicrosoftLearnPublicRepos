# Browse, open, and save files in Microsoft 365 for mobile

After you've integrated with Microsoft 365 for mobile, users can browse, open and save files from your storage location directly in the Microsoft Office apps. And they can open their Office files from your storage location. This section describes the user experience for browsing, opening and saving files from Microsoft 365 for mobile for Mobile.

## Open and edit files from Microsoft 365 for mobile

1. User selects **Add a Place** in their Office app.

   ![A screenshot that shows adding a place in the iOS backstage.](https://learn.microsoft.com/en-us/microsoft-365/cloud-storage-partner-program/mobile/images/scenario-add.png)

2. A list of places displays and the user selects **Contoso**.

   ![A screenshot that shows choosing a place from an available list.](https://learn.microsoft.com/en-us/microsoft-365/cloud-storage-partner-program/mobile/images/scenario-add2.png)

3. The user goes through Contoso’s OAuth 2.0 flow.

   ![A screenshot that shows an OAuth authentication screen.](https://learn.microsoft.com/en-us/microsoft-365/cloud-storage-partner-program/mobile/images/scenario-oauth.png)

4. The user can now browse files stored on Contoso and open them.

   ![A screenshot that shows browsing a place after it's been added in the backstage.](https://learn.microsoft.com/en-us/microsoft-365/cloud-storage-partner-program/mobile/images/scenario-browse.png)

5. The user can edit the file.

   ![A screenshot that shows editing a file in Office for iOS.](https://learn.microsoft.com/en-us/microsoft-365/cloud-storage-partner-program/mobile/images/scenario-edit.png)

## Open files from Office 365 for Android

1. User selects **Add a Place** in their Office app.

   ![A screenshot that shows adding a place in the Android backstage.](https://learn.microsoft.com/en-us/microsoft-365/cloud-storage-partner-program/mobile/images/scenario-add-android.png)

2. A list of places displays and the user selects **Contoso**.

   ![A screenshot that shows choosing a place from an available list on Android.](https://learn.microsoft.com/en-us/microsoft-365/cloud-storage-partner-program/mobile/images/scenario-add2-android.png)

3. The user goes through Contoso’s OAuth 2.0 flow.

   ![A screenshot that shows an OAuth authentication screen on Android.](https://learn.microsoft.com/en-us/microsoft-365/cloud-storage-partner-program/mobile/images/scenario-oauth-android.png)

4. The user can now browse through files stored on Contoso and open them.

   ![A screenshot that shows browsing a place after it's been added in the backstage on Android.](https://learn.microsoft.com/en-us/microsoft-365/cloud-storage-partner-program/mobile/images/scenario-browse-android.png)

5. The user can edit the file.

   ![A screenshot that shows editing a file in \|Office Android\|.](https://learn.microsoft.com/en-us/microsoft-365/cloud-storage-partner-program/mobile/images/scenario-edit-android.png)

## Open and edit files from your Cloud Storage App

1. User browses to a file on your iOS or Android app.

   ![A screenshot that shows browsing in a storage app.](https://learn.microsoft.com/en-us/microsoft-365/cloud-storage-partner-program/mobile/images/scenario-app-browse.png)

2. User selects Edit.

   ![A screenshot that shows previewing the file within a storage app.](https://learn.microsoft.com/en-us/microsoft-365/cloud-storage-partner-program/mobile/images/scenario-preview.png)


   Note


   If you do not have an in-app preview, you might open Office in other screens.

3. The file opens in Office and any saves go back to your service directly.

   ![A screenshot that shows editing a file in \|Office iOS\| or \|Office Android\|.](https://learn.microsoft.com/en-us/microsoft-365/cloud-storage-partner-program/mobile/images/scenario-edit.png)
