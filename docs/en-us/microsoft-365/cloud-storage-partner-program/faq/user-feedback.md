# How should users give feedback to Microsoft regarding Microsoft 365 for the web?

Bugs/issues or compliments should be reported using the in-app feedback form, which can be launched via *File ‣ Help ‣ Give Feedback* or the *Help Improve Microsoft 365* button on the status bar.

The feedback form also has a link to UserVoice if the user chooses *I have a suggestion*.
