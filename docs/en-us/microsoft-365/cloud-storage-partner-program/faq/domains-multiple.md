# Can I add more than one domain to the WOPI domain allow list?

Yes, you can have multiple entries on both the test and production allow lists. A maximum of 10 test or production domain entries are allowed in each partner's WOPI allow list. We reserve the right to limit production domains assigned to a partner.

Note

Any domains added to the allow list must be owned by the partner. Microsoft doesn't permit domains associated with a partner that aren't owned and controlled by that partner.

To request changes to your domain entries, submit the [**CSPP Environment Change Request**](https://forms.office.com/r/09LyKD6TPg).

Important

Changes to settings require time to make. Any changes to Microsoft-configured settings **will take 4-5 weeks to fully roll out**. This includes changes to the [**WOPI domain allow list**](https://learn.microsoft.com/en-us/microsoft-365/cloud-storage-partner-program/online/build-test-ship/settings#wopi-domain-allow-list), and applies to both the production and test environments
