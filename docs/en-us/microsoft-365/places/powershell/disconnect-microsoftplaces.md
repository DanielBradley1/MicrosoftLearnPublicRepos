# Disconnect-MicrosoftPlaces

Use the Disconnect-MicrosoftPlaces cmdlet to disconnect the connections that you created using the Connect-MicrosoftPlaces cmdlet.

## Syntax

```powershell
Disconnect-MicrosoftPlaces
```

## Description

This cmdlet is the counterpart to the Connect-MicrosoftPlaces cmdlet.

This cmdlet disconnects any connections and clears the cache. After a successful disconnect, you can't successfully run any cmdlets for your organization.

## Parameters

No parameters are exposed for this command.
