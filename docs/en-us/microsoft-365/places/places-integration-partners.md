# Microsoft Places integration partners

Note

Microsoft doesn't endorse the partners listed on this page. The partners identified don't represent an exhaustive list, so other partners may be able to support the referenced integrations. All services offered by partners are subject to their own terms and conditions. Microsoft doesn't guarantee the quality, reliability, or accuracy of the services provided by third-party partners. Any issues or disputes arising from the use of third-party services should be addressed directly with such partners.

With Microsoft Places, customers can connect to a growing ecosystem of AI-powered workplace partners.

The following list of software integration partners can aid in streamlining and enhancing Places across three key areas:

- Directory and floorplan conversion
- Data integration
- Application hosting

For support on deploying Microsoft Places and integrating with these partners, go to the [Microsoft Places Partner Directory](https://cloudpartners.transform.microsoft.com/ms-places-directory).

## Places directory and floorplan conversion

Convert and import floorplans and spatial data to support the onboarding and ongoing management of Places. For more information about directory and floorplan conversion, go to [Configure floorplans](https://learn.microsoft.com/en-us/microsoft-365/places/setting-up-maps-in-places).

## Application hosting

Enable services and amenities unique to each workplace location by engaging with partners from the Microsoft Teams apps marketplace and other sources. Example applications can include visitor management, signage, IT ticketing, facilities ticketing, food service, and so on. For more information about application hosting and Places, go to [Add services to buildings](https://learn.microsoft.com/en-us/microsoft-365/places/services-in-places).
