# Export your data

Should you wish to retain automation test scripts or download test results for future reference? Here is the guidance to export data from your existing account. If further guidance is needed, don't hesitate to let us know by [submit a support request](https://aka.ms/TestBaseSupport).

## Export your packages and scripts

To download your application packages and test scripts, please access your Test Base account and select **Manage packages > Select the application you want to export > Download package.**

[![Screenshot of manage packages.](https://learn.microsoft.com/en-us/microsoft-365/test-base/media/export-your-data-1.png?view=o365-worldwide)](https://learn.microsoft.com/en-us/microsoft-365/test-base/media/export-your-data-1.png?view=o365-worldwide#lightbox)

## Export your test results

To export a test result summary, you may go to **Test summary > Export all results to CSV**. \(Note: In-place upgrade results summary export is not supported by default, please [submit a request](https://aka.ms/TestBaseSupport) if needed.\)

[![Screenshot of Test summaries.](https://learn.microsoft.com/en-us/microsoft-365/test-base/media/export-your-data-2.png?view=o365-worldwide)](https://learn.microsoft.com/en-us/microsoft-365/test-base/media/export-your-data-2.png?view=o365-worldwide#lightbox)

For more detailed test execution logs, **Select the package from Test Summary page > Select desired Windows version > Download Log files**:

[![Screenshot for showing the download link.](https://learn.microsoft.com/en-us/microsoft-365/test-base/media/export-your-data-3.png?view=o365-worldwide)](https://learn.microsoft.com/en-us/microsoft-365/test-base/media/export-your-data-3.png?view=o365-worldwide#lightbox)

You may also click **See details** and **Download** log files and test execution videos from test detail page. \(Note: Videos are reserved for seven days after test completion.\)

[![Screenshot of page of test results.](https://learn.microsoft.com/en-us/microsoft-365/test-base/media/export-your-data-4.png?view=o365-worldwide)](https://learn.microsoft.com/en-us/microsoft-365/test-base/media/export-your-data-4.png?view=o365-worldwide#lightbox)

More details about how to analyze downloaded reports, refer to [Downloading and Analyzing Test Result Files \| Microsoft Learn](https://learn.microsoft.com/en-us/microsoft-365/test-base/download-analyze-test-result-files?view=o365-worldwide).

## Export your usage records

To download your billing usage records, go to **Billing hub > Usage Console > Export all results to CSV**.

[![Screenshot for showing the export button.](https://learn.microsoft.com/en-us/microsoft-365/test-base/media/export-your-data-4.png?view=o365-worldwide)](https://learn.microsoft.com/en-us/microsoft-365/test-base/media/export-your-data-4.png?view=o365-worldwide#lightbox)
