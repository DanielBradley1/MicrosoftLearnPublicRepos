# Understand your usage cost

Important

**Test Base for Microsoft 365 will transition to end-of-life \(EOL\) on May 31, 2024.** We're committed to working closely with each customer to provide support and guidance to make the transition as smooth as possible. If you have any questions, concerns, or need assistance, [submit a support request](https://aka.ms/TestBaseSupport).

Note

Test Base now offers the billing hub feature to help users understand their test usage and cost.

## Usage console under Billing hub

By access the new "Usage console" under the "Billing hub" section from portal, user will be able to review their Total usage for the selected period, Free hour balance, and the Billable cost based on the usage.

**Prep Step**

1. Sign in with your Test Base account.
2. In the navigation bar on the left, select Usage console under Billing Hub

[![Usage console.](https://learn.microsoft.com/en-us/microsoft-365/test-base/media/usagecost01-usage-console.png?view=o365-worldwide)](https://learn.microsoft.com/en-us/microsoft-365/test-base/media/usagecost01-usage-console.png?view=o365-worldwide#lightbox)

Users can switch between different time periods or specify customized start end date up to three months from the current date.

[![Switch time.](https://learn.microsoft.com/en-us/microsoft-365/test-base/media/usagecost02-switch-time.png?view=o365-worldwide)](https://learn.microsoft.com/en-us/microsoft-365/test-base/media/usagecost02-switch-time.png?view=o365-worldwide#lightbox)

Usage details by package and test type can be further reviewed in the lower section after you select the "Expand all". There normally will be one or more test executions for a particular package scheduled for a specific test type on the target platform.

[![Usage details.](https://learn.microsoft.com/en-us/microsoft-365/test-base/media/usagecost03-usage-details.png?view=o365-worldwide)](https://learn.microsoft.com/en-us/microsoft-365/test-base/media/usagecost03-usage-details.png?view=o365-worldwide#lightbox)

Clicking on the "Detail" column pops up the detailed execution records for all the executions including the execution ID, usage hour breakdown by free hour portion and paid hour portion.

[![Execution records.](https://learn.microsoft.com/en-us/microsoft-365/test-base/media/usagecost04-execution-records.png?view=o365-worldwide)](https://learn.microsoft.com/en-us/microsoft-365/test-base/media/usagecost04-execution-records.png?view=o365-worldwide#lightbox)

In other, Export function is provided to download the detailed usage report for your own analysis or reporting purposes.

[![Export function.](https://learn.microsoft.com/en-us/microsoft-365/test-base/media/usagecost05-export-function.png?view=o365-worldwide)](https://learn.microsoft.com/en-us/microsoft-365/test-base/media/usagecost05-export-function.png?view=o365-worldwide#lightbox)

Note

Be remind that usage console currently shows all test usage records at subscription level. You might notice test activities from other test accounts if you have more than one Test Base account recreated under the subscription.
