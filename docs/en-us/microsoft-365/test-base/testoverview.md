# Test your application on Test Base

Important

**Test Base for Microsoft 365 will transition to end-of-life \(EOL\) on May 31, 2024.** We're committed to working closely with each customer to provide support and guidance to make the transition as smooth as possible. If you have any questions, concerns, or need assistance, [submit a support request](https://aka.ms/TestBaseSupport).

In this section, you'll learn how to create packages with different types of applications for uploading and testing on **Test Base**. Application types consist of the following values:

![Package publish prompts.](https://learn.microsoft.com/en-us/microsoft-365/test-base/media/testoverview01.png?view=o365-worldwide)

- **Test Binaries files**

  See [Creating and Testing Binary Files on Test Base](https://learn.microsoft.com/en-us/microsoft-365/test-base/testapplication?view=o365-worldwide) to prepare a package with a Binary application file \(that is, .exe, .msi\) for uploading and testing.
- **Intunewin app**

  See [Test your Intune app on Test Base](https://learn.microsoft.com/en-us/microsoft-365/test-base/testintuneapplication?view=o365-worldwide) to prepare a package with an Intune application file \(.intunewin\) for uploading and testing.
- **Pre-built Zip package**

  See [Uploading pre-built zip package](https://learn.microsoft.com/en-us/microsoft-365/test-base/uploadapplication?view=o365-worldwide) if you already have an offline built package in .zip format.
- **Clone existing package**

  See [Clone an existing package](https://learn.microsoft.com/en-us/microsoft-365/test-base/clonepackage?view=o365-worldwide) to create a new package by duplicating your previously published package.
