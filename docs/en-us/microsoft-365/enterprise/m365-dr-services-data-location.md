# Microsoft 365 services data locations

This article provides links to data location information for Microsoft 365 services, including services eligible for [*Durable Commitments on Data Location*](https://learn.microsoft.com/en-us/microsoft-365/enterprise/m365-dr-key-terms-definitions?view=o365-worldwide#table-12-key-terms-and-definitions) and additional Microsoft 365 services.

For definitions of italicized terms, see [Key terms and definitions](https://learn.microsoft.com/en-us/microsoft-365/enterprise/m365-dr-key-terms-definitions?view=o365-worldwide).

Note

The **Denmark** [*Local Region Geography*](https://learn.microsoft.com/en-us/microsoft-365/enterprise/m365-dr-key-terms-definitions?view=o365-worldwide#table-12-key-terms-and-definitions) launched on April 1, 2026. See [Advanced Data Residency](https://learn.microsoft.com/en-us/microsoft-365/enterprise/m365-dr-adr-overview?view=o365-worldwide) if your organization requires the migration of your Microsoft 365 [*Customer Data*](https://learn.microsoft.com/en-us/microsoft-365/enterprise/m365-dr-key-terms-definitions?view=o365-worldwide#table-12-key-terms-and-definitions) to Denmark and [*Data Residency*](https://learn.microsoft.com/en-us/microsoft-365/enterprise/m365-dr-key-terms-definitions?view=o365-worldwide#table-12-key-terms-and-definitions) commitments for this region.

Note

[*Tenants*](https://learn.microsoft.com/en-us/microsoft-365/enterprise/m365-dr-key-terms-definitions?view=o365-worldwide#table-12-key-terms-and-definitions) in certain *Local Region Geographies* have access to **[Advanced Data Residency](https://learn.microsoft.com/en-us/microsoft-365/enterprise/m365-dr-adr-overview?view=o365-worldwide)** which provides more *Data Residency* commitments for certain in scope services. These *Local Region Geographies* are Australia, Austria, Brazil, Canada, Chile, Denmark, France, Germany, India, Indonesia, Israel, Italy, Japan, Malaysia, Mexico, New Zealand, Norway, Poland, Qatar, South Africa, South Korea, Spain, Sweden, Switzerland, Taiwan, United Arab Emirates, and United Kingdom.

## Overview

To find where *Customer Data* is stored for a specific Microsoft 365 service:

1. Use the [Data Location Card](https://learn.microsoft.com/en-us/microsoft-365/enterprise/m365-dr-data-location-card?view=o365-worldwide) in the Microsoft 365 admin center for *Tenant*-specific information
2. Use the links below for service-specific *Data Residency* documentation

## Services with Durable Commitments on Data Location

Select the link for each service to understand *Data Residency* commitments and how to determine data location.

- Audit \(Premium\)
