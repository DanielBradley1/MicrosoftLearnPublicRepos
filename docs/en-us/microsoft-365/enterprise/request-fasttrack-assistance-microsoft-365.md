# Request FastTrack assistance for Microsoft 365

The FastTrack request for assistance \(RFA\) form is now available in the [Microsoft 365 admin center](https://go.microsoft.com/fwlink/p/?linkid=2226341) and the [Microsoft 365 Setup portal](https://go.microsoft.com/fwlink/?linkid=2320164). FastTrack provides eligible customers with access to technical specialists at no added cost. Submit a request for assistance and our specialists can help you deploy Microsoft 365, strengthen your security posture, and prepare for broad AI adoption across your organization. See [eligible plans](https://learn.microsoft.com/en-us/microsoft-365/fasttrack/eligibility) for details.

## Submit an RFA in the Microsoft 365 admin center

1. Go to the [Deployment assistance](https://go.microsoft.com/fwlink/p/?linkid=2226341) area in the Microsoft 365 admin center.
2. Select **Request assistance**.

   After you submit the request, you'll receive an RFA ID and have the option to provide feedback about your experience.

## Submit an RFA at the Microsoft 365 Setup portal

1. Go to the [Microsoft 365 Setup portal](https://go.microsoft.com/fwlink/?linkid=2320164).
2. Select **Request assistance**.

   After you submit the request, you'll receive an RFA ID and have the option to provide feedback about your experience.

## View and manage RFA requests

The **Request history** section is where you can review existing RFA details. Tenant admins can approve or decline submitted deployment requests.

For tenant admins:

1. Go to the [Deployment assistance](https://go.microsoft.com/fwlink/p/?linkid=2226341) area in the Microsoft 365 admin center.
2. Scroll down to the **Request history** section.
3. Select an RFA from the list to view details about the request.

   To **approve** or **decline** a pending request, **select** the **Status** tab.

For non-admins:

1. Go to the [Microsoft 365 Setup portal](https://go.microsoft.com/fwlink/?linkid=2320164).
2. Scroll down to the **Request history** section.
3. Select an RFA from the list to view details about the request.
