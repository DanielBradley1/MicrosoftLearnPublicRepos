# Non-Microsoft 365 services data locations

This article provides data location information for Microsoft services outside of Microsoft 365.

For definitions of italicized terms, see [Key terms and definitions](https://learn.microsoft.com/en-us/microsoft-365/enterprise/m365-dr-key-terms-definitions?view=o365-worldwide).

## Overview

[*Data Residency*](https://learn.microsoft.com/en-us/microsoft-365/enterprise/m365-dr-key-terms-definitions?view=o365-worldwide#table-12-key-terms-and-definitions) for Microsoft 365 services is described in the [Data Location Card](https://learn.microsoft.com/en-us/microsoft-365/enterprise/m365-dr-data-location-card?view=o365-worldwide) and [Microsoft 365 services data locations](https://learn.microsoft.com/en-us/microsoft-365/enterprise/m365-dr-services-data-location?view=o365-worldwide).

For *Data Residency* information about other Microsoft services, use the links below.

## Microsoft 365-adjacent services

The following services are commonly used alongside Microsoft 365 but are part of separate product families with their own *Data Residency* documentation.

### Microsoft Entra ID

Microsoft Entra ID \(formerly Azure Active Directory\) is part of the Microsoft Entra product family. For where Entra ID stores [*Customer Data*](https://learn.microsoft.com/en-us/microsoft-365/enterprise/m365-dr-key-terms-definitions?view=o365-worldwide#table-12-key-terms-and-definitions) by region, see [Microsoft Entra data locations](https://aka.ms/aaddatamap).

### Microsoft Intune

Microsoft Intune is part of the Microsoft Intune product family \(formerly Microsoft Endpoint Manager\). For details on data storage locations and processing, see [Data storage and processing in Intune](https://learn.microsoft.com/en-us/intune/intune-service/protect/privacy-data-store-process#storage-locations).
