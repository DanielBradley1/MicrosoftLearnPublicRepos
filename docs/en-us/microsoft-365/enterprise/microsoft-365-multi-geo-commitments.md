# Microsoft 365 Multi-Geo: Data commitments

For [eligible customers](https://learn.microsoft.com/en-us/microsoft-365/enterprise/microsoft-365-multi-geo?view=o365-worldwide#licensing) that purchase [*Multi-Geo*](https://learn.microsoft.com/en-us/microsoft-365/enterprise/m365-dr-key-terms-definitions?view=o365-worldwide#table-12-key-terms-and-definitions), Microsoft makes commitments to store in-scope [*Customer Data*](https://learn.microsoft.com/en-us/microsoft-365/enterprise/m365-dr-key-terms-definitions?view=o365-worldwide#table-12-key-terms-and-definitions) in the applicable [*Geography*](https://learn.microsoft.com/en-us/microsoft-365/enterprise/m365-dr-key-terms-definitions?view=o365-worldwide#table-12-key-terms-and-definitions), including \(a\) in the [*Default Geography*](https://learn.microsoft.com/en-us/microsoft-365/enterprise/m365-dr-key-terms-definitions?view=o365-worldwide#table-12-key-terms-and-definitions) for the [*Tenant*](https://learn.microsoft.com/en-us/microsoft-365/enterprise/m365-dr-key-terms-definitions?view=o365-worldwide#table-12-key-terms-and-definitions) and \(b\) in a [*Satellite Geography*](https://learn.microsoft.com/en-us/microsoft-365/enterprise/m365-dr-key-terms-definitions?view=o365-worldwide#table-12-key-terms-and-definitions) for user data \(as determined by [*PDL*](https://learn.microsoft.com/en-us/microsoft-365/enterprise/m365-dr-key-terms-definitions?view=o365-worldwide#table-12-key-terms-and-definitions)\). Refer to [Key terms and definitions](https://learn.microsoft.com/en-us/microsoft-365/enterprise/m365-dr-key-terms-definitions?view=o365-worldwide#table-12-key-terms-and-definitions) for more information.

The commitments are specified as follows.

## Exchange Online

The following *Customer Data* is stored in the applicable *Geography*:

- Exchange Online mailbox content \(e-mail body, calendar entries, and the content of e-mail attachments\)

## SharePoint/OneDrive

The following *Customer Data* is stored in the applicable *Geography*:

- SharePoint site content and the files stored within that site and files uploaded to OneDrive

## Microsoft Teams

The following *Customer Data* is stored in the applicable *Geography*:

Microsoft Teams chat messages \(including private messages, channel messages, meeting messages and images used in chats\), and, for customers using Microsoft Stream \(on SharePoint\), meeting recordings

## Microsoft 365 Copilot and Microsoft 365 Copilot Chat

The following *Customer Data* is stored in the applicable *Geography*:

- "Content of Interactions" such as the user's prompt and the response from Microsoft Copilot or Microsoft Copilot Chat, including citations to any information used to ground Microsoft Copilot's response.

Note

For Microsoft 365 Copilot Cowork please refer to the limitations described [here](https://learn.microsoft.com/en-us/microsoft-365/enterprise/m365-dr-service-copilot?view=o365-worldwide)
