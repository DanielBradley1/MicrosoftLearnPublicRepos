# Network planning and performance tuning for Microsoft 365

Before you deploy for the first time or migrate to Microsoft 365, you can use the information in these articles to estimate the bandwidth you need and then to test and verify that you have enough bandwidth to deploy or migrate to Microsoft 365. For an overview, see: [Network and migration planning for Microsoft 365](https://learn.microsoft.com/en-us/microsoft-365/enterprise/network-and-migration-planning?view=o365-worldwide).

## Performance tuning and troubleshooting resources for Microsoft 365

Once you have Microsoft 365 deployed, you can optimize your performance by using the articles in this section. If you experience performance degradation, you can also use these articles to troubleshoot issues.

For Microsoft 365 network planning guidance, see the [Networking roadmap for Microsoft 365](https://learn.microsoft.com/en-us/microsoft-365/enterprise/networking-roadmap-microsoft-365?view=o365-worldwide). Also, take a look at the [top 10 tips for optimizing and troubleshooting your Microsoft 365 network connectivity](https://learn.microsoft.com/en-us/archive/blogs/onthewire/top-10-tips-for-optimising-troubleshooting-your-office-365-network-connectivity).

**[Tune Exchange Online performance](https://learn.microsoft.com/en-us/microsoft-365/enterprise/tune-exchange-online-performance?view=o365-worldwide)**: Use these articles to fine tune Exchange Online performance.

**[Prepare your organization's network for Microsoft Teams](https://learn.microsoft.com/en-us/microsoftteams/prepare-network)**: Use these articles to optimize your network for Teams.

**[Tune Skype for Business Online performance](https://learn.microsoft.com/en-us/microsoft-365/enterprise/tune-skype-for-business-online-performance?view=o365-worldwide)**: Use these articles to fine tune Skype for Business Online performance.

**[Tune SharePoint performance](https://learn.microsoft.com/en-us/microsoft-365/enterprise/tune-sharepoint-online-performance?view=o365-worldwide)**: Use these articles to fine tune SharePoint performance.

**[Tune Project Online performance](https://support.office.com/article/12ba0ebd-c616-42e5-b9b6-cad570e8409c)**: Use this article to fine tune Project Online performance.
