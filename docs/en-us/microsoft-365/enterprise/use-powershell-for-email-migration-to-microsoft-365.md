# How to use PowerShell to migrate email to Microsoft 365

*This article applies to both Microsoft 365 Enterprise and Office 365 Enterprise.*

Administrators often migrate email from existing systems when they first set up Microsoft 365. The following articles describe how to migrate email by using Windows PowerShell:

- [Use PowerShell to perform a cutover migration to Microsoft 365](https://learn.microsoft.com/en-us/microsoft-365/enterprise/use-powershell-to-perform-a-cutover-migration-to-microsoft-365?view=o365-worldwide)
- [Use PowerShell to perform an IMAP migration to Microsoft 365](https://learn.microsoft.com/en-us/microsoft-365/enterprise/use-powershell-to-perform-an-imap-migration-to-microsoft-365?view=o365-worldwide)
- [Use PowerShell to perform a staged migration to Microsoft 365](https://learn.microsoft.com/en-us/microsoft-365/enterprise/use-powershell-to-perform-a-staged-migration-to-microsoft-365?view=o365-worldwide)
