# Where your Microsoft 365 customer data is stored

This article explains data residency commitments for Microsoft 365 services and seeks to help organizations understand where their data is stored.

Note

The **Denmark** *Local Region Geography* launched on April 1, 2026. See [Advanced Data Residency](https://learn.microsoft.com/en-us/microsoft-365/enterprise/advanced-data-residency?view=o365-worldwide) if your organization requires the migration of your Microsoft 365 customer data to Denmark and data residency commitments for this region.

Note

*Tenants* in certain *Local Region Geographies* have access to **[Advanced Data Residency](https://learn.microsoft.com/en-us/microsoft-365/enterprise/advanced-data-residency?view=o365-worldwide)** which provides more data residency commitments for certain in scope services. These *Local Region Geographies* are Australia, Austria, Brazil, Canada, Chile, Denmark, France, Germany, India, Indonesia, Israel, Italy, Japan, Malaysia, Mexico, New Zealand, Norway, Poland, Qatar, South Africa, South Korea, Spain, Sweden, Switzerland, Taiwan, United Arab Emirates, and United Kingdom.

Select the link for each of the Microsoft 365 services to understand the current data residency and data residency commitments.
