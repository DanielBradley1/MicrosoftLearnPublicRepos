# Microsoft Copilot

## Microsoft Copilot

Microsoft Copilot is an AI-powered assistant that uses large language models \(LLMs\). It integrates with your data, with Microsoft Graph, and with Microsoft 365 Apps, like Word, Excel, PowerPoint, Outlook, Microsoft Teams, and more. Microsoft Copilot provides real-time intelligent assistance, enabling users to enhance their creativity, productivity, and skills. FastTrack deployment assistance for Microsoft Copilot helps customers with license assignment, adoption, extending Microsoft Copilot, and measuring the impact and business value of Microsoft Copilot.

FastTrack provides remote guidance and best practices for:

- Readiness:

  - Ensuring required products and features are enabled for optimal Copilot performance.
  - Addressing oversharing risks using SharePoint Advanced Management and Purview.
  - Reviewing Microsoft Copilot license assignment.
  - Setting up Copilot Chat for non-Microsoft Copilot licensed users.
  - Configuring Copilot settings in the Microsoft 365 Admin Center.

- Adoption:

  - Using the [Copilot Success Kit](https://go.microsoft.com/fwlink/?linkid=2282402) to highlight the foundational components of successful adoption.
  - Providing guidance on top usage scenarios and resources for training and skilling.
  - Setting up and using Copilot Analytics and Copilot Control System to assess adoption, usage, and impact.
  - Equipping users with skills for effective prompting in Copilot Chat with Microsoft Copilot user enablement sessions.

- [Microsoft Copilot agents](#microsoft-copilot-agents).

### Out of scope

- Providing project management and implementation.
- Providing data governance assessment.
- Setting up consumption licensing, e.g., Copilot Studio pay-as-you-go.
- Providing custom reports, scenarios, or content.
- Creating and implementing an adoption and change management strategy or plan.
- Providing end-user training.

## Microsoft Copilot Chat

Microsoft Copilot Chat is an AI-powered tool that enhances work efficiency by providing intelligent assistance within the Microsoft 365 ecosystem. It uses advanced machine learning to offer personalized recommendations, automate tasks, and analyze data. This tool integrates with various Microsoft 365 applications, helping users streamline workflows and boost productivity. Its intuitive interface and real-time support make it an essential tool for modern workplaces.

FastTrack provides remote guidance for:

- Readiness and Deployment:

  - Ensuring technical prerequisites are met for enabling Copilot Chat.
  - Providing instructions on managing user access and permissions to maintain control and security.
  - Pinning Copilot Chat for easy access and enhanced user experience.
  - Setting up web grounding to ensure secure and compliant usage.

- Adoption and Value:

  - Using the Copilot Success Kit to highlight key adoption components.
  - Providing resources to train and skill users on Microsoft Copilot Chat.
  - Identifying opportunities to maximize the benefits and efficiency of Copilot Chat and making recommendations for driving healthy usage and adoption across the organization.
  - Reviewing top usage scenarios and reports to monitor adoption and usage patterns.

### Out of scope

- Project management and implementation.
- End-user training.
- Custom scenarios or content creation.
- Data governance assessment.

## Microsoft Copilot Cowork

Microsoft Copilot Cowork helps you delegate complex, multi-step work across Microsoft 365. Describe the outcome you want, and Cowork can gather information, coordinate tasks across apps, create deliverables, and keep you informed along the way. You remain in control through review and approval.

FastTrack provides remote guidance for:

- Cowork fundamentals and value guidance.
- Guidance on consumption.
- Configuring Cowork.
- Configuring billing policies.
- Validating usage-based billing, spending policies, and monitoring.

### Out of scope

- Project management and implementation.
- End-user training.
- Data governance assessment.
- Custom reports, scenarios, or content.
- Creating and implementing an adoption and change management strategy or plan.
- Setting up Azure subscriptions.

## Microsoft Copilot Agents

Microsoft Copilot agents empower organizations to integrate AI capabilities directly into their workflows, driving productivity and innovation. FastTrack provides deployment guidance to help customers securely enable Copilot agents. FastTrack also offers advanced deployment guides to accelerate the successful implementation of Copilot agents.

FastTrack provides remote guidance for:

- Agent fundamentals and capabilities covering prebuilt Microsoft agents, SharePoint agents, Agent Builder, and Copilot Studio.
- Agent management and governance \(included with Microsoft cloud subscriptions, plus premium capabilities included with Agent 365 subscriptions\). This includes implementing agent access, sharing, data protection, Power Platform governance, and application lifecycle management \(ALM\).
- Best practices for building agents tailored to business scenarios by using different agent capabilities.
- Enabling Work IQ \(enterprise data tools such as Copilot connectors, federated connectors, MCP tools, and related technologies\).
- Consumption billing, including consumption and cost governance, Copilot Credits, spend monitoring, budgets, alerts, and spending controls.
- Measuring and reporting on Copilot agent usage through the Power Platform admin center, Copilot Analytics, and the Microsoft 365 admin center.

### Out of scope

- Providing project management or implementation services.
- Providing data governance assessments.
- Commercial licensing planning, including required licenses, quantities, and pay-as-you-go options.
- Providing custom reports, scenarios, or content.
- Creating adoption and change management plans or end-user training.
- Creating custom agents using Microsoft Copilot Studio, Microsoft 365 Agents Toolkit, Azure AI Foundry, Semantic Kernel, Microsoft 365 Agents SDK, or Fabric data agents.
- Setting up Azure DevOps or Git for source control as part of ALM.
- Configuring non-Microsoft-published or custom Copilot connectors.
- Dynamics 365 \(D365\) agent creation.

## Microsoft Copilot Analytics

Microsoft Copilot Analytics provides organizations with deep insights about how their employees are using Copilot. With these insights, companies can make better-informed decisions about how to deploy Copilot, and how to more broadly improve employee productivity. Copilot Analytics is designed to empower every IT and business leader to measure adoption and business impact of Copilot, Copilot Chat, and Copilot agents, with Copilot Dashboard, Copilot Analytics reports, Advanced Reporting powered by Viva Insights, and Copilot reports, in the Microsoft Admin Center.

FastTrack provides remote guidance for:

- Reporting to the correct stakeholders within your organization.
- Assigning licenses and roles.
- Configuring Microsoft Copilot Dashboard access.
- Best practices for leveraging Copilot Dashboard and Advanced Reporting.
- Configuring Advanced Reporting \(privacy settings, admin settings, and minimum group size\).
- Uploading additional employee attributes with an organizational data file.
- Uploading survey data for Copilot sentiment analysis.
- Uploading business data for the Copilot Business Outcome report.
- Understanding data availability through data quality reporting.
- Additional settings configuration for OOTB \(out-of-the-box\) Copilot Analytics reporting and Advanced Reporting templates \(for the following customizations\):

  - Active Copilot User definition.
  - Minimum group-size privacy threshold.
  - Report date ranges.

- Copilot Power BI reporting templates in Advanced Reporting, including:

  - OOTB templates.
  - Query creation in support of feature capabilities.

- Advanced Reporting privacy and partition settings.
- Copilot usage reporting within Microsoft Admin Center \(MAC\).

### Out of scope

- Interpreting or analyzing data in Copilot Analytics, Advanced Reporting query results, or MAC usage reports.
- Recommendations on data validation, verification, or use.
- Custom reports or custom queries \(*Advanced Reporting, powered by Viva Insights provides reporting through data export or data connection*\).
- Third-party integrations.
- Project management \(including defining success criteria\).
- Adoption and change management activities.
- Metrics interpretation for reporting tools, to drive adoption, determine ROI, or define KPIs.
- Troubleshooting or investigating product-related issues \(*Power BI, PowerShell*\).
- Automation implementation for HR data uploads.

Note

For more information on Microsoft Copilot metrics \(*available in Viva Insights*\) and how those metrics are calculated, see the [metric definitions](https://learn.microsoft.com/en-us/viva/insights/advanced/reference/metrics) and [glossary](https://learn.microsoft.com/en-us/viva/insights/advanced/reference/glossary).
