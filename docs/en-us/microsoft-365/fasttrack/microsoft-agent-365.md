# Microsoft Agent 365

Microsoft Agent 365 enables organizations to securely deploy and scale AI agents by providing centralized visibility, lifecycle management, and policy-driven governance across their agent ecosystem. By extending Microsoft security and compliance capabilities to AI agents, Agent 365 and Agent ID help organizations manage agents plus secure agent identities and access to resources through integrated protections from Microsoft Entra, Defender, and Purview.

FastTrack provides remote guidance for:

- Enabling agent discovery and inventory through the Agent 365 Registry.
- Providing an overview of A365 SDK/CLI integration.
- Enabling identity and access control.
- Configuring baseline security controls across Microsoft Entra, Microsoft Defender, and Microsoft Purview to enforce least-privilege access, security posture detection and response, and data protection for agents and AI apps.
- Onboarding model-context protocol \(*MCP*\)-connected services \(Outlook, Teams, SharePoint, OneDrive, Word, Calendar\).
- Managing agent-lifecycle workflows.
- Establishing monitoring and response workflows for ongoing agent operations.
- Creating an agent blueprint including the principal identity, sponsor and owner assignment, and blueprint access.
- Associating an agent identity with an agent blueprint and sponsor and owner assignment.
- Reviewing agent-related activities including sign-ins and audited activities.
- Configuring conditional access policies and ID protection features for agents.
- Configuring ID governance features including access packages and lifecycle Workflows for agents.
- Configuring network controls for agents.

## Out of scope

- Registering agents through A365 SDK/CLI.
- Developing custom MCP.
- Connecting third-party MCP.
- Providing project management, hands-on implementation, or running the customer's deployment on their behalf.
- Building, customizing, or troubleshooting customer-specific agents \(including writing custom code, creating custom APIs, developing custom connectors/integrations, or performing code reviews\).
- Performing a formal security, risk, or data governance assessment \(FastTrack can provide guidance on recommended controls and operating models\).
- Operating the customer's ongoing monitoring, incident response, compliance investigations, or internal support processes.
