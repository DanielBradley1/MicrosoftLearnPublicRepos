# Microsoft Security Copilot

## Overview

Microsoft Security Copilot is a natural language, assistive experience that helps security professionals work more efficiently across end-to-end scenarios, such as incident response, threat hunting, intelligence gathering, and posture management.

FastTrack deployment assistance provides remote guidance and best practices to help customers access, understand, and operationalize Security Copilot embedded experiences and available agents.

## FastTrack support

FastTrack provides **walkthrough-based guidance** to help customers succeed with Security Copilot experiences and agents - and understand how they fit into day-to-day security workflows.

### Security Copilot embedded experiences

Covers how Security Copilot is integrated into Microsoft Security products to support investigation, analysis, and response.

**FastTrack provides walkthroughs and guidance for Security Copilot embedded experiences, including:**

- **Microsoft Security** [**Copilot in Entra**](https://learn.microsoft.com/en-us/microsoft-365/fasttrack/microsoft-entra-id#copilot-in-entra)

  Walkthroughs of identity-focused scenarios where Security Copilot helps analyze signals, risks, and investigation context.
- **Microsoft Security** [**Copilot in Defender**](https://learn.microsoft.com/en-us/microsoft-365/fasttrack/microsoft-defender#copilot-in-defender)

  Guidance with how Security Copilot supports investigation and response workflows across Microsoft Defender security solutions.
- **Microsoft Security** [**Copilot in Purview**](https://learn.microsoft.com/en-us/microsoft-365/fasttrack/microsoft-purview#copilot-in-purview)

  Guidance for how Security Copilot assists with data security and compliance scenarios within Microsoft Purview experiences.
- **Microsoft Security** [**Copilot in Intune**](https://learn.microsoft.com/en-us/microsoft-365/fasttrack/microsoft-intune#copilot-in-intune)

  Walkthroughs of device and endpoint management scenarios supported by Security Copilot in Intune.

**Across these embedded experiences, FastTrack focuses on:**

- Common investigation and analysis scenarios supported by Security Copilot.
- How embedded experiences align to day-to-day security workflows.

### Security Copilot agents

This covers which agents are available and how they improve experiences to support security tasks. FastTrack provides guidance and walkthroughs for available Security Copilot agents, including:

- Understanding the purpose and capabilities of Security Copilot agents.
- Reviewing agent-supported scenarios and how agents assist with security tasks.
- Demonstrating how agents interact with Security Copilot experiences.

---

### Out of Scope

FastTrack does not provide:

- Detailed pricing guidance \(*contact your account team or reseller for support*\).
- Walkthroughs of the standalone Security Copilot experience.
- Designing or building new custom agents.
- Deploying third-party agents.
