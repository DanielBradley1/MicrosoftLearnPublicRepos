# Understand Microsoft Copilot reports

The Microsoft 365 admin center contains usage reports that let you see how people in your organization are using Microsoft Copilot and Copilot agents. For general information about how to get to the reports dashboard, who has permission to view the reports, and how to show details in the reports, see [Microsoft 365 Reports in the admin center](https://learn.microsoft.com/en-us/microsoft-365/admin/activity-reports/activity-reports).

The following Microsoft Copilot reports are available:

- [Microsoft 365 reports in the admin center - Agent usage in Microsoft Copilot](https://learn.microsoft.com/en-us/microsoft-365/admin/activity-reports/microsoft-365-copilot-agents)

  The Microsoft Copilot agent usage report shows the adoption of agents in Microsoft Copilot in your organization. For agent activity on a given day, the report becomes available within 72 hours of the end of that day \(in UTC\).
- [Microsoft 365 admin center Microsoft Copilot readiness - Microsoft 365 admin \| Microsoft Learn](https://learn.microsoft.com/en-us/microsoft-365/admin/activity-reports/microsoft-365-copilot-readiness)

  The Microsoft Copilot readiness report shows which users are technically eligible for Copilot. From the report, you can assign licenses and monitor usage of Microsoft 365 apps that Copilot integrates best with. The report becomes available within 72 hours, and once available, the usage data in the report can have up to a maximum of 72 hours latency.
- [Microsoft 365 admin center Microsoft Copilot usage - Microsoft 365 admin \| Microsoft Learn](https://learn.microsoft.com/en-us/microsoft-365/admin/activity-reports/microsoft-365-copilot-usage)

  In the Microsoft Copilot usage report, you can view a summary of users' adoption, retention, and engagement with Microsoft Copilot and its associated enabled apps, including agent usage. For Copilot activity on a given day, the report becomes available within 72 hours of the end of that day \(in UTC\).
- [Microsoft 365 admin center - Microsoft Copilot Chat usage - Microsoft 365 admin \| Microsoft Learn](https://learn.microsoft.com/en-us/microsoft-365/admin/activity-reports/microsoft-copilot-usage)

  The Microsoft Copilot Chat usage dashboard provides insights into active usage of Microsoft Copilot Chat. The report includes total active users, average daily active users, total prompts submitted, and average prompts submitted per user. Usage insights can be viewed as totals and trends for the past 7, 30, 90, or 180-day periods. The report also shows the last activity date, prompts submitted, and active days per user. By default, this data is anonymized.
- [Microsoft 365 reports in the admin center - Copilot Search usage - Microsoft 365 admin \| Microsoft Learn](https://learn.microsoft.com/en-us/microsoft-365/admin/activity-reports/microsoft-365-copilot-search-usage)

  The Microsoft Copilot Search usage report provides an overview of Copilot Search usage within the Microsoft Copilot app. It helps you understand adoption and engagement trends for Copilot Search capabilities.

  The Copilot Search usage report provides a detailed view of both organizational and individual user activity with Copilot Search across platforms. It includes trend charts for active usage and search activity at the organization level, and insights into each user's search behavior during a selected timeframe. User behaviors are reflected in the report within one hour. With these insights, you can easily track Copilot Search usage trends and make informed decisions on how to drive further adoption within your organization.
- [Microsoft 365 reports in the admin center - Copilot credits - Microsoft 365 admin \| Microsoft Learn](https://learn.microsoft.com/en-us/microsoft-365/admin/activity-reports/microsoft-365-copilot-credits)

  The Copilot credits report helps you manage metered consumption costs for Microsoft Copilot Chat. This report gives you visibility into credits used associated with your Microsoft Copilot pay-as-you-go billing policies and includes key metrics such as:
- Total credits used
- Cumulative and daily time series
- Credits used per user, per agent, per billing policy, and per agent-user pair
