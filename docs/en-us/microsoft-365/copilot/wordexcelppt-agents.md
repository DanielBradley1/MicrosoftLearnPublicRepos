# Get started with Word, Excel, and PowerPoint Agents in Microsoft Copilot

Word, Excel, and PowerPoint Agents are premium capabilities available only to users with a paid Microsoft 365 Copilot license. These agents use advanced AI models to create Word, Excel, and PowerPoint files within Microsoft Copilot.

## Admin enablement and controls

These agents exclusively use Anthropic's AI models. This AI model must be enabled. These requirements are mandatory for [Word, Excel, and PowerPoint Agents](https://learn.microsoft.com/en-us/microsoft-365/copilot/wordexcelppt-agents) to function.

Administrators can disable access to reasoning models at any time. If your organization decides to stop using Anthropic models, you can block the provider in the admin center, which removes the agents for licensed users.

[Word, Excel, and PowerPoint Agents](https://support.microsoft.com/topic/76691f5e-bb19-4029-a34d-33a00e0a0c4f) in the Microsoft Copilot app are installed by Microsoft. For users with a paid Microsoft 365 Copilot license, the agents appear in the **Tools** menu and under **All Agents** in the left navigation pane when Anthropic models are enabled for the tenant. Admins can manage these agents similarly to other agents that were installed by [Microsoft](https://learn.microsoft.com/en-us/microsoft-365/copilot/copilot-agent-install).

If administrators disable Anthropic models, [Word, Excel, and PowerPoint Agents](https://support.microsoft.com/topic/76691f5e-bb19-4029-a34d-33a00e0a0c4f) are hidden and unavailable, including for users with a paid Microsoft 365 Copilot license.

### Connect to AI models in the Microsoft 365 admin center

For steps on how to connect to Anthropic's AI models, see [Anthropic as a subprocessor for Microsoft Online Services](https://learn.microsoft.com/en-us/microsoft-365/copilot/connect-to-ai-subprocessor).

### Disable connection to AI models

For steps on how to disable the connection to Anthropic's AI models, see [Disable connection to Anthropic's models](https://learn.microsoft.com/en-us/microsoft-365/copilot/connect-to-ai-subprocessor#disable-connection-to-anthropics-models).

## Data Privacy and Security

Important

Starting on January 7, 2026, Anthropic will operate as a Microsoft subprocessor for these Microsoft Copilot capabilities under Microsoft's direction and contractual safeguards. This includes coverage under the [Microsoft Product Terms](https://www.microsoft.com/licensing/terms?msockid=344e0e6ad66c6b3e19441848d7416abd) and the [Microsoft Data Protection Addendum \(DPA\)](https://www.microsoft.com/licensing/docs/view/Microsoft-Products-and-Services-Data-Protection-Addendum-DPA?lang=18&msockid=344e0e6ad66c6b3e19441848d7416abd) with Microsoft remaining accountable for Anthropic's compliance under our contractual commitments. In addition, use of Anthropic models in Microsoft Copilot will fall under our [Enterprise Data Protection](https://learn.microsoft.com/en-us/microsoft-365/copilot/enterprise-data-protection) and will be covered by the Customer Copyright Commitment. Note that Anthropic models are currently excluded from EU Data Boundary and when applicable, in-country/region processing commitments.

Anthropic as a subprocessor is being introduced gradually and is not yet available to all organizations. During this phased rollout, some features may be limited for your organization. Full availability is expected by the end of February 2026.

For more information, see [Anthropic as a subprocessor](https://learn.microsoft.com/en-us/microsoft-365/copilot/connect-to-ai-subprocessor).

## Enterprise Data

As part of the premium, licensed Microsoft 365 Copilot experience, Word, Excel, and PowerPoint Agents can access organizational data. The agents use Work IQ to retrieve information from files, emails, meetings, and sites that the licensed user has permission to access, similar to other Microsoft 365 Copilot experiences.

Microsoft ensures secure handling of data, when integrating with AI models. Microsoft performs all searches, and only relevant context is shared with the reasoning model. So the data provided is limited to what you are authorized to view, with sensitivity labels and compliance policies fully respected.

Generated content is stored securely in OneDrive. All documents created by these agents are saved within your organization's tenant, maintaining governance and compliance standards.

## Limitations and support

Access to Word, Excel, and PowerPoint Agents requires a paid Microsoft 365 Copilot license. The agents aren't available to Copilot Chat users who don't have a Microsoft 365 Copilot license. Licensed users can use the agents in all officially supported Microsoft Copilot languages. For the complete list of supported languages, see [Supported languages for Microsoft Copilot](https://support.microsoft.com/office/supported-languages-for-microsoft-365-copilot-94518d61-644b-4118-9492-617eea4801d8).

Feedback mechanisms exist for reporting inaccuracies or inappropriate content; support articles provide further guidance.
