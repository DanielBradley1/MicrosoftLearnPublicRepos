# Welcome users, create organizational messages, and enable feedback for Microsoft Copilot

[Microsoft Copilot](https://learn.microsoft.com/en-us/microsoft-365/copilot/microsoft-365-copilot-overview) is an AI-powered productivity tool that helps users with everyday tasks.

As part of your [Microsoft Copilot adoption](https://learn.microsoft.com/en-us/microsoft-365/copilot/microsoft-365-copilot-enablement-resources), send a welcome email to your Microsoft Copilot users on license assignment that announces Microsoft Copilot and its features. You can also enable feedback for Microsoft Copilot users.

[![Diagram that shows the send welcome email and enable feedback step to adopt and enable Microsoft Copilot.](https://learn.microsoft.com/en-us/microsoft-365/copilot/media/microsoft-365-copilot-enablement-resources/adopt-copilot-welcome-email-feedback.png)](https://learn.microsoft.com/en-us/microsoft-365/copilot/media/microsoft-365-copilot-enablement-resources/adopt-copilot-welcome-email-feedback.png#lightbox)

Additionally, admins can use Organizational Messaging in the Microsoft Admin Center to deliver tailored in-product messages to your users directly through Teams.

This article provides information about how to send users a welcome email, enable feedback, send organizational messages, and review the Microsoft Copilot usage activity report.

This article applies to:

- Microsoft Copilot

## Send welcome email

After you assign a Microsoft Copilot license to a user, the system automatically sends a notification email that can look like the following email.

![An image of an email introducing Microsoft Copilot and its capabilities that an admin can provide to users.](https://learn.microsoft.com/en-us/microsoft-365/copilot/media/copilot-welcome-email-jan.png)

The welcome email also includes a link to [Microsoft Copilot help and learning](https://support.microsoft.com/copilot-skilling).

Send an in-product notification to your users through Organizational Messaging.

## Organizational messages

Admins can send a customizable in-product message through Teams with organizational messaging in the Microsoft Admin Center. After you [set up Microsoft Copilot and assign licenses](https://learn.microsoft.com/en-us/microsoft-365/copilot/microsoft-365-copilot-setup) to your users, notify them with your message in-product telling them that they can now use Microsoft Copilot.

Admins can configure their message through the Microsoft 365 admin center.

[![An image of the Set up Microsoft Copilot page in the Microsoft 365 admin center.](https://learn.microsoft.com/en-us/microsoft-365/copilot/media/promote-using-copilot.png)](https://learn.microsoft.com/en-us/microsoft-365/copilot/media/promote-using-copilot.png#lightbox)

1. In your Microsoft 365 admin center, in the navigation pane, select **Setup**.
2. On the Setup page, in the **Featured collections** section, select **Advanced deployment guides & assistance**.
3. Select **Set up Microsoft Copilot**.
4. On the **Set up Microsoft Copilot** page, in the **Promote using Microsoft Copilot** tile, select **Schedule message**.
5. The **Organization messages** pane displays and shows the default message and how it displays to your users. If you choose to use it, select the recipients, schedule when and how regularly you want the message to be delivered to your users, and then select **Schedule message**.

![An image of the default organization message for Copilot users.](https://learn.microsoft.com/en-us/microsoft-365/copilot/media/organizational-message-copilot.png)

### Create a custom message

If you want to create a custom message instead of using the default one, at the bottom of the **Organizational messages** pane, select **More customization**. You can then create and deliver messages to targeted groups of users in your organization.

![An image of the Organizational messages page in which you can create a custom message.](https://learn.microsoft.com/en-us/microsoft-365/copilot/media/create-custom-message.png)

1. Select **Create a message**.
2. Select an objective, such as Adoption, Onboarding, Sustainability, or Training. Select **Next**.
3. Select where you want your message to display, such as the Notifications area, Taskbar, Teaching popover, or Windows spotlight. Select **Next**.
4. Choose to create your own message or start with a premade template. Select **Next**.
5. Write your message, and then select **Next**.
6. Select your target audience, and then select **Next**.
7. Schedule how long and how often you want your message to appear to your recipients. Select **Next**.
8. Review your selections, and then select **Schedule**.

## Enable feedback

Enable all feedback settings for the Microsoft 365 Apps.

This option allows Microsoft Copilot users to provide details with a thumbs up or thumbs down reaction to a Copilot prompt response.

- To enable the feedback for your users, use the [cloud policy service](https://config.office.com) or group policies.

When all the policies are enabled, users can provide logs, screenshots, and a contact email address for their feedback submission.

## Review the Copilot usage activity report

After your users start using Copilot, run and review the [Microsoft Copilot usage report](https://learn.microsoft.com/en-us/microsoft-365/admin/activity-reports/microsoft-365-copilot-usage). This report summarizes user adoption, retention, and engagement with Microsoft Copilot.

- Find the report in the [Microsoft 365 admin center](https://admin.microsoft.com) > **Reports** > **Usage**.

To learn more about the Microsoft Copilot reports, see [Microsoft Copilot reporting options for admins](https://learn.microsoft.com/en-us/microsoft-365/copilot/microsoft-365-copilot-reports-for-admins).
