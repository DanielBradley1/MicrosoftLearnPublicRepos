# View costs and billing for Microsoft Copilot pay-as-you-go

The [Microsoft Copilot pay-as-you-go service](https://learn.microsoft.com/en-us/microsoft-365/copilot/pay-as-you-go/overview) offers a flexible and cost-effective way for organizations to access Copilot services.

You can monitor your organization's consumption of the pay-as-you-go service in the [Microsoft 365 admin center](https://admin.microsoft.com) > [Cost Management](https://learn.microsoft.com/en-us/microsoft-365/commerce/use-cost-mgmt) page for each Microsoft 365 pay-as-you-go service that you use, including Microsoft Copilot Chat and SharePoint agents.

This article explains how administrators can view cost and billing details for pay-as-you-go.

This article applies to:

- Microsoft Copilot
- SharePoint agents

## Access usage and billing information

To view detailed reports on Copilot usage and the associated costs, use the following steps:

1. Sign in to the [Microsoft 365 admin center](https://admin.microsoft.com) with one of the following administrator roles:

   - Global administrator
   - Billing administrator

2. Go to **Billing** > **Cost Management**.
3. On the **Cost Management** page, under **Service family**, you see a service-level view of costs based on Copilot usage.

Important

Microsoft recommends that you use roles with the fewest permissions. Using roles with the fewest permissions helps improve security for your organization. Global Administrator is a highly privileged role that should be limited to emergency scenarios when you can't use an existing role. For more information, see [About administrator roles in the Microsoft 365 admin center](https://learn.microsoft.com/en-us/microsoft-365/admin/add-users/about-admin-roles).

To view costs in the Azure portal, see [What is Microsoft Cost Management?](https://learn.microsoft.com/en-us/azure/cost-management-billing/costs/overview-cost-management). You can filter the accumulated costs by using tags, like `m365copilotchat`:

[![Screenshot of the Azure portal that shows the Cost Management page filtered on the Microsoft Copilot Chat cost.](https://learn.microsoft.com/en-us/microsoft-365/copilot/media/copilot-pay-azure.png)](https://learn.microsoft.com/en-us/microsoft-365/copilot/media/copilot-pay-azure.png#lightbox)

Billed amounts are updated daily and sometimes more frequently. It can take 24 hours after usage of a service to show in Microsoft Cost Management.
