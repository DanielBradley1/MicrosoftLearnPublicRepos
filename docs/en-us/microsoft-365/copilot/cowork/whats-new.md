# What's new in Copilot Cowork

This article lists recent features, improvements, and changes in Microsoft 365 Copilot Cowork. Get a full guide to Cowork's capabilities in [Use Cowork](https://learn.microsoft.com/en-us/microsoft-365/copilot/cowork/use-cowork).

## September 2026

### New features

| Feature | Description | Learn more |
| --- | --- | --- |
| App skill \(Frontier\) | Create lightweight, interactive apps from a description without writing code. Refine your app in chat, open it, publish it, and share it with people in your organization. | [Build apps with the App skill](https://learn.microsoft.com/en-us/microsoft-365/copilot/cowork/use-cowork#build-apps-with-the-app-skill-frontier) |
| Claude Fable 5.1 model | Fable 5.1 is now available in the model selector as the most advanced model for ambitious work, replacing Fable 5. | [Choose a model for Cowork](https://learn.microsoft.com/en-us/microsoft-365/copilot/cowork/cowork-models) |
| GPT 6 Astra model | GPT 6 Astra is now available in the model selector as the latest model for tough problems. | [Choose a model for Cowork](https://learn.microsoft.com/en-us/microsoft-365/copilot/cowork/cowork-models) |
| Plugins on the mobile app | Plugins are discoverable and configurable on the mobile app. To find them, select the attach menu \(**+**\) > **Skills**. | [Cowork common questions](https://learn.microsoft.com/en-us/microsoft-365/copilot/cowork/cowork-faq#does-cowork-work-on-mobile-devices) |

### Enhancements

| Feature | Description | Learn more |
| --- | --- | --- |
| Edit existing Office files | Edit Word, Excel, and PowerPoint files in OneDrive and SharePoint while preserving the shared file and its existing version history. | [Edit an existing Office file](https://learn.microsoft.com/en-us/microsoft-365/copilot/cowork/use-cowork#edit-an-existing-office-file) |

## August 2026

### Enhancements

| Feature | Description | Learn more |
| --- | --- | --- |
| Workspace file input for plugin tools | Plugin connector tools can now accept files from your session as input. Plugin authors declare a tool parameter with `contentEncoding: base64`, and Cowork resolves the workspace file to content before calling the tool—so a tool can convert a document, analyze an image, or attach a file to another system. | [Accept files from the Cowork workspace](https://learn.microsoft.com/en-us/microsoft-365/copilot/cowork/cowork-plugin-development#accept-files-from-the-cowork-workspace) |
| Local browser use | This feature moved from Frontier to general availability to all Microsoft 365 Copilot tenants. Cowork can complete web tasks for you in Microsoft Edge on your device, using your existing sign-ins and your organization's policies. Requires that Edge is installed. |  |

### New features

| Feature | Description | Learn more |
| --- | --- | --- |
| Event-driven tasks | Set up tasks that run when something happens, such as when you receive a matching email or a Teams message \(including when you're @mentioned\). Describe what to watch for in your message, and Cowork proposes the automation for you to review and confirm. Event-driven tasks appear alongside scheduled prompts on the **Automations** page. | [Set up event-driven tasks](https://learn.microsoft.com/en-us/microsoft-365/copilot/cowork/use-cowork#set-up-event-driven-tasks) |

## June 2026 \(general availability\)

Cowork is now generally available to all Microsoft 365 Copilot tenants. This release brings new models, image generation, browser use, the Customize page, and consumption billing.

### New features

| Feature | Description | Learn more |
| --- | --- | --- |
| General availability | Microsoft 365 Copilot Cowork is generally available to all Microsoft 365 Copilot tenants worldwide in tier-1 languages. | [Cowork overview](https://learn.microsoft.com/en-us/microsoft-365/copilot/cowork/) |
| Claude Opus 4.8 model | Opus 4.8 is now available as a model option in the model selector. | [Use Cowork](https://learn.microsoft.com/en-us/microsoft-365/copilot/cowork/use-cowork) |
| Claude Sonnet 5 model | Sonnet 5 is now available in the model selector as the efficient choice for everyday tasks, replacing Sonnet 4.6. | [Choose a model for Cowork](https://learn.microsoft.com/en-us/microsoft-365/copilot/cowork/cowork-models) |
| Claude Fable 5 \(Preview\) model | Fable 5 is now available in preview in the model selector for your toughest challenges. Fable 5 is off by default; an admin turns it on in the Microsoft 365 admin center under Copilot settings. Fable 5 requires data retention, so your prompts and responses for that model are retained by the model provider, and Cowork shows a banner while it's selected. | [Data retention](https://learn.microsoft.com/en-us/microsoft-365/copilot/cowork/cowork-models#data-retention) |
| Image generation | Cowork can generate images using ChatGPT Images 2.0. Ask for an image in chat and Cowork saves it to your conversation and your OneDrive output folder. | [Generate images](https://learn.microsoft.com/en-us/microsoft-365/copilot/cowork/use-cowork#generate-images) |
| Local browser use \(Frontier\) | Cowork can complete web tasks for you in Microsoft Edge on your device, using your existing sign-ins and your organization's policies. In Frontier and requires that Edge is installed. | [Use the local browser with Cowork](https://learn.microsoft.com/en-us/microsoft-365/copilot/cowork/cowork-local-browser) |
| Customize page | A single **Customize** page now hosts your plugins and your skills. Browse, install, and share plugins and skills in one place; create new skills with a guided conversation. | [Customize Cowork](https://learn.microsoft.com/en-us/microsoft-365/copilot/cowork/cowork-customize) |
| Guided skill builder | Create a new skill by selecting **Add** > **Create new** in the **Customize** > **Skills** tab. Cowork walks you through naming, describing, and writing the skill in a guided conversation. | [Create custom skills](https://learn.microsoft.com/en-us/microsoft-365/copilot/cowork/use-cowork#create-custom-skills) |
| Upload a skill | Import a skill file \(`.md`, `.zip`, or `.skill`\) from the **Customize** > **Skills** tab by selecting **Add** > **Upload skill**. | [Upload a skill](https://learn.microsoft.com/en-us/microsoft-365/copilot/cowork/cowork-customize#upload-a-skill) |
| Upload a plugin package | Upload your own plugin package from the **Customize** > **Plugins** tab. Cowork converts a Claude or other compatible package into a publishable package, including bundled skills and connectors. | [Upload a plugin package](https://learn.microsoft.com/en-us/microsoft-365/copilot/cowork/cowork-customize#upload-a-plugin-package) |
| Share skills and plugins | Share a skill or plugin you created with only yourself or specific people in your organization, and re-share to keep recipients up to date when you make changes. | [Share skills and plugins](https://learn.microsoft.com/en-us/microsoft-365/copilot/cowork/cowork-customize#share-skills-and-plugins) |
| Brand templates | Cowork applies your organization's brand template \(fonts, colors, logos, layouts\) to the PowerPoint decks it creates. | [Use brand templates with Cowork](https://learn.microsoft.com/en-us/microsoft-365/copilot/cowork/cowork-brand-templates) |
| Usage-based billing | Cowork now uses usage-based billing. Admins see usage in the Microsoft 365 admin center and can set per-user or per-group limits. | [Usage-based billing](https://learn.microsoft.com/en-us/microsoft-365/copilot/cowork/cowork-admin-governance#usage-based-billing). |
