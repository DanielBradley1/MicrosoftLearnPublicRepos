# copilotPackagePolicyTemplate: copy

Important

APIs under the `/beta` version are subject to change. Use of these APIs in production applications is not supported.

Create a new custom [copilotPackagePolicyTemplate](https://learn.microsoft.com/en-us/microsoft-365/copilot/extensibility/api/admin-settings/package/resources/copilotpackagepolicytemplate) by copying the bound source on the server. The source isn't changed.

This proposed contract requires matching schema and receiving-service qualification; neither delegated nor application execution is established by the declaration alone.

Copy preserves source settings and metadata not exposed by public reads. Reconstructing a template from its public projection isn't equivalent. The source comes from the bound route, not another body identifier; the new template's ID is generated by the server. Collection create isn't supported.

Important

Access to the Package Management API requires a [Microsoft Agent 365](https://www.microsoft.com/microsoft-agent-365) license.

## Permissions

Choose the permission or permissions marked as least privileged for this API. Use a higher privileged permission or permissions [only if your app requires it](https://learn.microsoft.com/en-us/graph/permissions-overview#best-practices-for-using-microsoft-graph-permissions). For details about delegated and application permissions, see [Permission types](https://learn.microsoft.com/en-us/graph/permissions-overview#permission-types). To learn more about these permissions, see the [permissions reference](https://learn.microsoft.com/en-us/graph/permissions-reference).

| Permission type | Least privileged permissions | Higher privileged permissions |
| :--- | :--- | :--- |
| Delegated \(work or school account\) | CopilotPackages.ReadWrite.All | Not available. |
| Delegated \(personal Microsoft account\) | Not supported. | Not supported. |
| Application | CopilotPackages.ReadWrite.All | Not available. |

Applicable tenant authority and receiving-service support are required separately from permission metadata.

## HTTP request

```http
POST https://graph.microsoft.com/beta/copilot/admin/catalog/policyTemplates/{policyTemplateId}/copy
```

## Request headers

| Name | Description |
| :--- | :--- |
| `Authorization` | Bearer token. Required. Learn more about [authentication and authorization](https://learn.microsoft.com/en-us/graph/auth/auth-concepts). |
| `Content-Type` | `application/json`. Required. |

## Request body

| Parameter | Type | Description |
| :--- | :--- | :--- |
| `description` | String | Optional and nullable. Omission copies the source description; explicit null clears it on the new template. |
| `displayName` | String | Required. Non-null, nonempty display name of the new custom template. |
| `policyConfiguration` | [copilotPackagePolicyConfiguration](https://learn.microsoft.com/en-us/microsoft-365/copilot/extensibility/api/admin-settings/package/resources/copilotpackagepolicyconfiguration) | Optional and nullable. Omit or supply null to copy the raw source configuration. A non-null object is a strictly validated complete replacement, not an overlay. |

The null-configuration behavior differs from [Update](https://learn.microsoft.com/en-us/microsoft-365/copilot/extensibility/api/admin-settings/package/copilotpackagepolicytemplate-update), which rejects explicit null. A supplied replacement must contain all applicable mandatory families and every required choice within a selected family. Default and optional families may be omitted. An explicit empty selected set is allowed only when no applicable mandatory family exists.

## Response

If successful, this method returns `200 OK` and one newly created [copilotPackagePolicyTemplate](https://learn.microsoft.com/en-us/microsoft-365/copilot/extensibility/api/admin-settings/package/resources/copilotpackagepolicytemplate), with a new server-generated `id`. It isn't a collection, `201 Created`, or a promised `Location` header contract.

Copy isn't idempotent. After a timeout or uncertain result, reconcile whether a new template was created before another attempt; don't blindly retry or assume rollback.

## Example

This illustrative request clears the new description and inherits the source configuration. The illustrative source is verified as unconfigured, so the returned configuration is null.

### Request

```http
POST https://graph.microsoft.com/beta/copilot/admin/catalog/policyTemplates/example-unconfigured-template/copy
Content-Type: application/json

{
  "displayName": "Example copied template",
  "description": null
}
```

### Response

```http
HTTP/1.1 200 OK
Content-Type: application/json

{
  "id": "example-new-template",
  "displayName": "Example copied template",
  "description": null,
  "policyConfiguration": null
}
```
