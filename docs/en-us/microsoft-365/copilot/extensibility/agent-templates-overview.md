# Agent Builder templates

Agent Builder templates are prebuilt starting points for the [declarative agents](https://learn.microsoft.com/en-us/microsoft-365/copilot/extensibility/overview-declarative-agent) you build in Agent Builder. A template is a scaffold: it supplies a description, instructions, and suggested prompts for a specific scenario. You refine that scaffold in Agent Builder, and add your own knowledge sources and capabilities, before the agent exists.

These templates are specific to Agent Builder.

## How a template fits into building an agent

Starting from a template changes only how you begin. The rest of the work happens in Agent Builder:

1. In Microsoft 365 Copilot, in the left pane, select **New agent**.
2. Under **Start with a template**, select the template you want to use.
3. On the **Describe** tab, use natural language to refine the template, including the agent name, description, and instructions.
4. On the **Configure** tab, add an icon, knowledge sources, and capabilities.
5. Select **Create**.

The agent doesn't exist until you select **Create**. Until then, you're editing the template scaffold.

For the full build and test procedure, including how to test your agent on the **Try it** tab, see [Build agents in Agent Builder](https://learn.microsoft.com/en-us/microsoft-365/copilot/extensibility/agent-builder-build-agents).

| [Customer Insight Assistant](https://learn.microsoft.com/en-us/microsoft-365/copilot/extensibility/agent-template-customer-insight) | Builds detailed customer profiles covering industry, products, priorities, leadership, competitors, and trends. |
| [Executive Briefing Agent](https://learn.microsoft.com/en-us/microsoft-365/copilot/extensibility/agent-template-executive-briefing) | Prepares executives for meetings and media with structured briefing documents, talking points, and post-meeting summaries. |
| [Idea Coach](https://learn.microsoft.com/en-us/microsoft-365/copilot/extensibility/agent-template-idea-coach) | Helps users develop and refine ideas and run more engaging, productive brainstorming sessions. |
| [Interview Question Assistant](https://learn.microsoft.com/en-us/microsoft-365/copilot/extensibility/agent-template-interview-questions) | Helps hiring managers and interviewers quickly draft high-quality interview questions. |
