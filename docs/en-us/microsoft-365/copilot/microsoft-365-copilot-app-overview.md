# Get started with the Microsoft Copilot app

The Microsoft Copilot client application is an everyday AI productivity app supported on web, desktop, and mobile, for both personal and work or school experiences from within the same client application.

Visual indicators in the app distinguish which account the user is logged into, including a "Work" label under the user's profile in the navigation pane when logged into work or school accounts. Users can switch between their Microsoft account \(personal\) and Microsoft Entra ID \(work or school\) account using the account switcher in their navigation pane.

Data entered in the Microsoft account \(personal\) experience does not flow into the Microsoft Entra ID \(work or school\) experience, and data entered in the Microsoft Entra ID \(work or school\) experience does not flow into the Microsoft account \(personal\) experience.

You can use the Microsoft Copilot app in the following client formats:

- Browser

  - [copilot.microsoft.com](https://copilot.microsoft.com/)

- Desktop app

  - [Windows](https://go.microsoft.com/fwlink/?LinkId=2370901)
  - [macOS](https://go.microsoft.com/fwlink/?linkid=2325114)

- Mobile app

  - [Android devices](https://go.microsoft.com/fwlink/p?linkid=2325433)
  - [iOS devices](https://go.microsoft.com/fwlink/?linkid=2256798)

The app features available for work or school experiences depend on the Microsoft 365 license\(s\) assigned to the user. Users with a Copilot license get the full Microsoft Copilot app experience.

Note

**The Microsoft 365 Copilot app is now called Microsoft Copilot**. The primary URL for accessing the updated Copilot app is changing from `m365.cloud.microsoft` to `copilot.cloud.microsoft`. To help ensure users' connections aren't blocked, see [recommended network configurations for Microsoft Copilot](https://learn.microsoft.com/en-us/microsoft-365/copilot/microsoft-365-copilot-requirements#network-requirements).

IT admins can configure some work or school user experiences in the Microsoft Copilot app from the Microsoft 365 admin center. To learn more, see [Microsoft Copilot app features that admins can control](https://learn.microsoft.com/en-us/microsoft-365/copilot/microsoft-365-copilot-app-admin-settings).

IT admins of work or school environments can limit their users from accessing the Copilot app with their Microsoft account \(personal account\) by using [Tenant Restrictions](https://learn.microsoft.com/en-us/entra/external-id/tenant-restrictions-v2#step-2-block-consumer-account-or-microsoft-account-tenants).

To customize a theme and differentiate work or school accounts from personal accounts, see [Customize the Microsoft 365 theme for your organization](https://learn.microsoft.com/en-us/microsoft-365/admin/setup/customize-your-organization-theme).

## Microsoft Copilot client app requirements

Note

Microsoft will start the broad rollout of the updated Microsoft Copilot application for commercial customers. To participate in the broad rollout, verify that your network allows access to the Microsoft Copilot endpoints. For more information, see [Prepare for broad roll out of the unified Microsoft Copilot application](https://learn.microsoft.com/en-us/windows/client-management/deploy-unified-copilot-app#prepare-for-broad-rollout-of-the-unified-microsoft-copilot-application).

### Network

- Allow [Microsoft 365 Unified Domains](https://learn.microsoft.com/en-us/microsoft-365/enterprise/urls-and-ip-address-ranges#microsoft-365-unified-domains) to support all aspects of AI-related enterprise services from Microsoft 365 in a user's work or school Copilot experience.
- Allow [Microsoft Copilot endpoints](https://learn.microsoft.com/en-us/microsoft-365/copilot/add-copilot-endpoints-allowlist) to support all aspects of the Microsoft Copilot client app.
