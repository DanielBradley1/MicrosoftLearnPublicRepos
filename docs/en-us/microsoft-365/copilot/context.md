# Org context

Org context lets authorized administrators add organization-wide definitions and guidance. Workforce Insights uses this information to interpret questions and results according to your organization’s terminology and business rules.

## Privacy and limitations

Org context can appear in responses, so treat everything you enter as broadly visible within your organization. Include only public or internally shareable organizational information. Do not include confidential, sensitive, privileged, restricted, personal, or employee-specific information.

Definitions and rules can be referenced in agent responses. AI-generated answers can vary, even when they use the same context. Org context helps Workforce Insights interpret organizational language and rules, but it does not add or change the underlying workforce data.

## Configure Org context

Use plain, direct language when configuring Org context. Define each term and explain when it applies. For calculations, state the formula or rule and identify the relevant attributes. Keep entries concise, avoid overlapping or contradictory definitions, and include only information that is safe to share broadly within your organization.

**Before you begin**

You need the AI Administrator or Organizational Data Source Administrator to configure Org context.

**To configure Org context**

1. Open the [Workforce Insights admin page](https://aka.ms/workforceinsightsadminhome).
2. Select **Org context**.
3. Download and complete the markdown template or enter text directly in the **Context** field.
4. Review the content for accuracy, clarity, and suitability for broad internal sharing.
5. Select **Save**.

Allow up to 15 minutes for the changes to take effect.

## Test Org context

After the changes take effect, test Org context with a representative set of realistic questions.

- Test questions that rely on each new term, definition, mapping, rule, or calculation.
- Try multiple phrasings, including acronyms and full terms.
- Confirm the intended results and test unrelated questions for unexpected effects.
- If needed, revise the context, save your changes, wait for them to take effect, and test again.
