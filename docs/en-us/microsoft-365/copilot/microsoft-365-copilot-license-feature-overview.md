# Compare Microsoft Copilot in Microsoft 365 E3, E5, and E7

Microsoft 365 E3, E5, and E7 provide different levels of security, compliance, governance, and AI capabilities. Use this article to compare the capabilities that help prepare your Microsoft 365 data for Microsoft Copilot and determine which license best supports your organization's requirements.

Important

Licensing availability and product terms can change. Confirm current eligibility and included capabilities in the applicable Microsoft product terms and service descriptions before you purchase or assign licenses.

For more information, see [Microsoft 365 Copilot service description](https://learn.microsoft.com/en-us/office365/servicedescriptions/office-365-platform-service-description/microsoft-365-copilot), [Microsoft Copilot pricing and plans](https://www.microsoft.com/copilot), and [Microsoft Copilot licensing](https://learn.microsoft.com/en-us/microsoft-365/copilot/copilot-license-options).

## Compare the licenses

The following table summarizes the primary differences among Microsoft 365 E3, E5, and E7.

Important

Microsoft 365 E7 includes the capabilities of Microsoft 365 E5 and adds Microsoft Copilot, the Microsoft Entra Suite, and Microsoft Agent 365 in a single license.

| Capability area | Microsoft 365 E3 | Microsoft 365 E5 | Microsoft 365 E7 |
| --- | --- | --- | --- |
| Microsoft 365 productivity apps, including Word, Excel, PowerPoint, and OneNote | Included | Included | Included |
| [Microsoft Copilot](https://learn.microsoft.com/en-us/microsoft-365/copilot/microsoft-365-copilot-overview) | Available as an add-on | Available as an add-on | Included |
| [Security](https://learn.microsoft.com/en-us/entra/) | Foundational identity with [Microsoft Entra ID P1](https://learn.microsoft.com/en-us/entra/fundamentals/licensing) and basic threat protection | Advanced identity with [Microsoft Entra ID P2](https://learn.microsoft.com/en-us/entra/fundamentals/licensing) and full [Microsoft Defender XDR](https://learn.microsoft.com/en-us/defender-xdr/microsoft-365-defender) capabilities | Microsoft 365 E5 capabilities, plus the full Microsoft Entra Suite and agent security |
| [Compliance and data governance](https://learn.microsoft.com/en-us/purview/) | Core Microsoft Purview capabilities | Advanced Microsoft Purview capabilities | Microsoft 365 E5 capabilities, plus agent-focused governance |
| [Microsoft Security Copilot](https://learn.microsoft.com/en-us/copilot/security/microsoft-security-copilot) | Not included | Included for eligible customers | Included for eligible customers |
| [Microsoft Agent 365](https://learn.microsoft.com/en-us/microsoft-365/admin/manage/agent-settings) | Not included | Not included | Included |

## Compare capabilities and outcomes

Copilot uses the permissions and controls applied to [organizational data in Microsoft 365](https://learn.microsoft.com/en-us/viva/organizational-data). Compare Microsoft 365 E3, E5, and E7 based on your organization's required outcomes and the capabilities that support them.

| Capability or outcome | Microsoft 365 E3 | Microsoft 365 E5 | Microsoft 365 E7 |
| --- | --- | --- | --- |
| Reduce oversharing and manage content with [SharePoint Advanced Management](https://learn.microsoft.com/en-us/microsoft-365/copilot/get-ready-copilot-sharepoint-advanced-management) | SharePoint administration and foundational governance controls. SharePoint Advanced Management requires the Microsoft Copilot add-on. | Advanced SharePoint and governance controls. SharePoint Advanced Management requires the Microsoft Copilot add-on. | Microsoft 365 E5 capabilities, plus SharePoint Advanced Management through the included Microsoft Copilot license and controls that extend to agent governance. |
| [Classify data](https://learn.microsoft.com/en-us/purview/sensitivity-labels) and [protect sensitive data](https://learn.microsoft.com/en-us/purview/dlp-learn-about-dlp) | Manual [sensitivity labeling](https://learn.microsoft.com/en-us/purview/sensitivity-labels) and core [data loss prevention](https://learn.microsoft.com/en-us/purview/dlp-learn-about-dlp) capabilities. | [Automatic labeling](https://learn.microsoft.com/en-us/purview/sensitivity-labels), broader [data loss prevention](https://learn.microsoft.com/en-us/purview/dlp-learn-about-dlp) coverage, and advanced information protection. | Microsoft 365 E5 capabilities, plus protection and governance controls that extend to Copilot experiences and AI agents. |
| [Audit](https://learn.microsoft.com/en-us/purview/audit-solutions-overview), [eDiscovery](https://learn.microsoft.com/en-us/purview/edisc), [records management](https://learn.microsoft.com/en-us/purview/data-lifecycle-management), and [compliance management](https://learn.microsoft.com/en-us/purview/compliance-manager) | Standard [audit](https://learn.microsoft.com/en-us/purview/audit-solutions-overview), core [eDiscovery](https://learn.microsoft.com/en-us/purview/edisc), [records management](https://learn.microsoft.com/en-us/purview/data-lifecycle-management), and foundational [compliance](https://learn.microsoft.com/en-us/purview/compliance-manager) capabilities. | Advanced [audit](https://learn.microsoft.com/en-us/purview//audit-solutions-overview) with 10-year retention, [eDiscovery](https://learn.microsoft.com/en-us/purview/edisc), investigation, [records management](https://learn.microsoft.com/en-us/purview/data-lifecycle-management), and [compliance](https://learn.microsoft.com/en-us/purview/compliance-manager) capabilities. | Microsoft 365 E5 capabilities, plus visibility and governance for Copilot and agent activity. |
| Manage [insider risk](https://learn.microsoft.com/en-us/purview/insider-risk-management-adaptive-protection) and [communication compliance](https://learn.microsoft.com/en-us/purview/communication-compliance) | Foundational compliance and protection controls. | [Insider Risk Management](https://learn.microsoft.com/en-us/purview/insider-risk-management-adaptive-protection), [Communication Compliance](https://learn.microsoft.com/en-us/purview/communication-compliance), [Adaptive Protection](https://learn.microsoft.com/en-us/purview/insider-risk-management-adaptive-protection), and related advanced controls. | Microsoft 365 E5 capabilities, plus risk and governance controls that extend to Copilot experiences and AI agents. |
| Secure AI-assisted workflows | Foundational Microsoft 365 [identity, access, and security controls](https://learn.microsoft.com/en-us/entra/fundamentals/licensing). | [Microsoft Security Copilot](https://learn.microsoft.com/en-us/copilot/security/microsoft-security-copilot) and [advanced threat, identity, and access protection](https://learn.microsoft.com/en-us/entra/fundamentals/licensing). | Microsoft 365 E5 capabilities, plus the Microsoft Entra Suite and security controls for AI agents. |
| Govern AI agents at enterprise scale with [Microsoft Agent 365](https://learn.microsoft.com/en-us/microsoft-365/admin/manage/agent-settings) | Not included. | Not included. | [Centralized agent governance, security, access, and lifecycle management](https://learn.microsoft.com/en-us/purview/deploymentmodels/depmod-sc-agents-deployment). |
