# Microsoft 365 migration overview

Whether you're consolidating tenants after a merger or acquisition, divesting a business unit, or moving from a third-party platform like Google Workspace, Microsoft 365 provides tools and guidance for each scenario. This article helps you identify the right migration path and get started.

## Tenant-to-tenant migrations

Tenant-to-tenant migration enables organizations to move user data and workloads between separate Microsoft 365 tenants. This functionality supports scenarios such as mergers, acquisitions, divestitures, and internal reorganizations.

You can migrate across tenants using individual workload tools, or through the Microsoft 365 Migration Orchestrator for coordinated, multi-workload moves.

For more information on the Orchestrator tool, see [An overview of tenant-to-tenant migration with orchestrator in Microsoft 365](https://learn.microsoft.com/en-us/microsoft-365/migration/migration-orchestrator-1-overview?view=o365-worldwide).

Note

The Microsoft 365 Orchestrator tool allows for cross-product migration, including Teams content.

For more information on individual product tenant-to-tenant migrations, see:

- [Cross-tenant mailbox migration](https://learn.microsoft.com/en-us/microsoft-365/migration/cross-tenant-mailbox-migration?view=o365-worldwide).
- [Cross-tenant SharePoint migration](https://learn.microsoft.com/en-us/microsoft-365/migration/cross-tenant-sharepoint-migration?view=o365-worldwide).
- [Cross-tenant OneDrive migration](https://learn.microsoft.com/en-us/microsoft-365/migration/cross-tenant-onedrive-migration?view=o365-worldwide).

## External to Microsoft 365 migrations

If you're moving from an external platform to Microsoft 365, use Migration Manager to centrally manage and monitor your migration. Migration Manager supports file shares, Google Workspace, Dropbox, Box, and other sources.

- [Migration paths for Exchange Online](https://learn.microsoft.com/en-us/exchange/mailbox-migration/decide-on-a-migration-path?toc=/microsoft-365/migration/toc.json&bc=/microsoft-365/migration/breadcrumb/toc.json).
