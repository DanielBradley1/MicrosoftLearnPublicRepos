# Microsoft Copilot addons for education

Microsoft Copilot addons for education are designed to enhance the educational experience by leveraging AI-powered tools. These addons help educators create lesson plans, quizzes, and other educational materials, provide AI-generated feedback on student work, and ensure secure collaboration. With seamless integration into Microsoft 365 apps like Teams, Word, and PowerPoint, these tools support personalized learning and improve productivity in the classroom.

## Microsoft Copilot in education

Microsoft Copilot for Education is an AI-powered assistant designed to enhance the educational experience for both educators and students. It helps educators save time by generating lesson plans, quizzes, rubrics, and other educational materials based on pedagogical requirements. Copilot aligns content to over five million education standards from 35 countries/regions, ensuring that materials meet specific educational criteria. Additionally, it provides AI-generated feedback on student work, helping educators offer timely and meaningful responses. With features like guided content generation, quiz creation, and secure collaboration, Microsoft Copilot supports personalized learning and improves overall productivity in the classroom. This tool seamlessly integrates with Microsoft 365 apps such as Teams, Word, and PowerPoint, making it a valuable resource for enhancing teaching and learning experiences.

- **Guided Content Generation**: Helps educators create materials like assignments, lesson plans, and lecture slides based on pedagogical requirements. It aligns content to over five million education standards from 35 countries/regions.
- **Quiz Generation**: Allows educators to generate quizzes and correct answers in Microsoft Forms, supporting students with step-by-step solutions and easy assignment of quizzes in Teams for Education.
- **AI Feedback**: Provides suggested AI feedback on student work, helping educators offer timely and meaningful responses.
- **Commercial Data Protection**: Ensures that user and organizational data are protected, with no eyes-on access by Microsoft and no use of data to train underlying AI models.
- **Integration with Microsoft 365 Apps**: Seamlessly integrates with apps like Teams, Word, and PowerPoint, enhancing productivity and collaboration.
- **Secure Collaboration**: Facilitates secure collaboration on educational content, ensuring data privacy and compliance with educational standards.

## Microsoft Copilot Studio in education

Microsoft Copilot Studio is an AI-powered assistant designed to enhance productivity and learning experiences in educational institutions. Starting January 1, 2024, Microsoft Copilot will be available to faculty and staff with Microsoft 365 A3 and A5 licenses at a cost per user per month, with a 300-seat minimum per tenant. This subscription provides access to advanced AI capabilities that assist in creating educational content, managing administrative tasks, and improving overall efficiency. Key features include guided content generation, AI feedback on student work, and seamless integration with Microsoft 365 apps like Teams, Word, and PowerPoint. Additionally, it ensures data protection by safeguarding user and organizational data, with no eyes-on access by Microsoft and no use of data to train underlying AI models. These features help educational institutions save time, create impactful content, and deepen learning experiences, ultimately enhancing the overall educational environment.

Key features include:

- **Guided Content Generation**: Helps educators create lesson plans, quizzes, and other educational materials.
- **AI Feedback**: Provides real-time feedback on student work, helping educators offer timely and meaningful responses.
- **Data Protection**: Ensures that user and organizational data are protected, with no eyes-on access by Microsoft and no use of data to train underlying AI models.
- **Integration with Microsoft 365 Apps**: Seamlessly integrates with apps like Teams, Word, and PowerPoint, enhancing productivity and collaboration.
