# Microsoft Education licenses \(MA0-MA2-MA3-MA5-MA7\)

These new phases will be update as the changes roll out. For details, see [Microsoft 365 Education portfolio evolution](https://learn.microsoft.com/en-us/training/educator-center/instructor-materials/microsoft-365-education-portfolio).
