# Microsoft 365 Education licenses - Microsoft 365 and Office 365 A5

This page provides an overview of the features included specifically in the Microsoft Education A5 \(advanced\) license. The A5 license also includes the features in the [A1 \(baseline\)](https://learn.microsoft.com/en-us/microsoft-365/education/guide/0-start-baseline/baseline-license) and [A3 \(standard\)](https://learn.microsoft.com/en-us/microsoft-365/education/guide/0-start-standard/standard-license) licenses, which aren't included here. For a list of features available in all education licenses, see [Microsoft 365 Education licenses](https://learn.microsoft.com/en-us/microsoft-365/education/guide/0-start/all-license).
