# Deploy Microsoft Learning Zone

Note

Starting January 1, 2026, Microsoft Learning Zone is available to everyone in eligible organizations by default, unless an administrator turns it off.

## What is Microsoft Learning Zone?

Microsoft Learning Zone is a Windows app that helps educators turn their ideas, standards, and teaching materials into interactive lessons that adapt to each learner. Educators can assign lessons for learners to complete at their own pace, teach them live in class, and use built-in reports to see where learners need support.

## Licensing and account requirements

Microsoft Learning Zone is available to organizations with a Microsoft 365 Education A1, A3, or A5 license. Educators must sign in with an account that belongs to an education tenant to create and manage lessons.

There's no additional cost for Learning Zone when it's used with an eligible education license. Institutions can adopt the app without separate procurement and keep administrative control over its availability.

## Device requirements

Educators can generate lessons on any Windows 11 PC:

- On a **Copilot+ PC**, lesson generation has no limits.
- On **other Windows 11 PCs**, each generation is limited to 10 slides. Generation on these devices is available until August 1, 2027.

All other Learning Zone capabilities, including editing, assigning, teaching, and sharing lessons, viewing reports, and using the ready-to-learn lesson library, are available on any Windows 11 PC.

Learners don't need a Windows app or new hardware. They can complete lessons in a web browser on computers and tablets, through a link, a join code, or a Microsoft Teams assignment. Phones aren't supported.

## Language support

Educators can generate lessons in English, English \(United Kingdom\), Spanish, Spanish \(Mexico\), French, Italian, Japanese, and Portuguese \(Brazil\). The app interface and the ready-to-learn lessons are available in more than 50 languages.

## Download and get started

Microsoft Learning Zone is distributed through the Microsoft Store. Educators install the app on a Windows 11 PC.

To download the app:

1. Search for **Microsoft Learning Zone** in the Microsoft Store, or open [https://aka.ms/getLZ](https://aka.ms/getLZ).
2. Select the app published by Microsoft Corporation.
3. Select **Install**, or **Update** if the app is already installed.

The app installs locally, and the Microsoft Store manages updates automatically, so you always have a supported version.

![Screenshot of the Microsoft Store page for the Microsoft Learning Zone app.](https://learn.microsoft.com/en-us/microsoft-365/education/guide/images/learning-zone/microsoft-store-learning-zone-app.png)

## Sign in

When you open Microsoft Learning Zone for the first time, sign in with your Microsoft 365 Education account, the same account you use for Microsoft 365 or Microsoft Teams. Learning Zone uses Microsoft's standard sign-in process, so there's no separate username or password to remember.

After you sign in, Learning Zone recognizes your organization and applies your institution's policies to your access, content creation, and sharing options. You stay signed in between sessions.

## After signing in

After you sign in, a short onboarding experience guides you to the home page. From the home page, you can:

1. Select **Create** to generate a new interactive lesson or a Kahoot! quiz.
2. Use the navigation bar to open **Home**, **Lessons**, **Discover**, and **Reports**.

![Screenshot of the Learning Zone home page, with numbered callouts for the Create button and the navigation bar.](https://learn.microsoft.com/en-us/microsoft-365/education/guide/images/learning-zone/learning-zone-home-page.png)

Note

Learners typically open Learning Zone lessons through a link or join code in a web browser, or through Microsoft Teams assignments or another supported LMS, so they don't need to install the Windows app. Learners who use the app can also explore the ready-to-learn lesson library on their own.

## Integrations

Microsoft Learning Zone works with the tools you already use, including Microsoft Teams Assignments, learning management systems connected through LTI, Google Classroom, and Kahoot!. Learning Zone handles the interactive lesson, while class discussions, assignments, feedback, and follow-up activities stay in your existing workflows.

## Privacy and security

Learning Zone operates within Microsoft's education security and privacy framework. Authentication, access control, and data handling follow the same standards used across Microsoft 365 Education services.

## Data collection

For information about the types of data that Microsoft Learning Zone collects, see [Data collection in Microsoft Learning Zone](https://support.microsoft.com/topic/data-collection-in-microsoft-learning-zone-c948c900-6c84-4649-a18f-e937909cd890).

## Data storage and compliance

User data collected through Microsoft Learning Zone is stored in the European Union, the United States, or Australia, in compliance with the General Data Protection Regulation \(GDPR\) and other applicable regulations. Some AI processing for lesson generation might take place in a different geography from where your data is stored.

## Turn off Microsoft Learning Zone for your organization

IT administrators can turn off Microsoft Learning Zone for their organization:

1. Go to the Learning Zone admin page at [https://aka.ms/LearningZoneAdmin](https://aka.ms/LearningZoneAdmin) and sign in with an administrator account.
2. Under **Access settings**, turn off access to Learning Zone.
3. Select **Save**.
