# Deploy Microsoft Learning Zone

Note

Starting January 1, 2026, Microsoft Learning Zone will be accessible to everyone by default unless an administrator explicitly chooses to disable it.

## What is Microsoft Learning Zone?

Microsoft Learning Zone is a Windows app that empowers educators by enabling them to generate personalized learning activities tailored to the unique needs of their students. The platform is designed to leverage the computing power of Copilot+ PC devices for content generation, enhancing teaching effectiveness and student engagement through customized educational experiences.

Microsoft Learning Zone is available for Microsoft 365 Education customers with A1, A3, and A5 licenses on a Copilot+ PC device.

Educators and students can download the app at [https://aka.ms/getLZ](https://aka.ms/getLZ).

## Regional support

Currently, Microsoft Learning Zone is available in English and Spanish.

## Data collection

Comprehensive information regarding the types of data collected through Microsoft Learning Zone is available in the official documentation. For further details, visit: [Data Collection in Microsoft Learning Zone - Microsoft Support.](https://support.microsoft.com/topic/data-collection-in-microsoft-learning-zone-c948c900-6c84-4649-a18f-e937909cd890)

## Data storage and compliance

User data collected through Microsoft Learning Zone is securely stored in the EU, US, and Australia, ensuring compliance with the General Data Protection Regulation \(GDPR\) and other applicable regulations. During the public preview access, Microsoft Learning Zone relies on cloud services that may be hosted in the US.

## Disabling Microsoft Learning Zone for your organization

IT administrators can disable Microsoft Learning Zone for their organization by turning on the appropriate toggle within the Admin page: [https://aka.ms/LearningZoneAdmin](https://aka.ms/LearningZoneAdmin).
