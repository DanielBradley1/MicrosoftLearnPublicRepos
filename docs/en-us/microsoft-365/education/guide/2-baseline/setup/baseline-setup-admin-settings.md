# Step 2: Configure tenant security center admin settings

Tip

Some of the URLs in this article will take you to another document set. If you would like to maintain your place in this document set's table of contents, right click the URLs to open them in a new window.

After you create your education tenant and added domains, you're ready to configure the admin settings.

1. Navigate to portal.office.com and sign in with your admin credentials.
2. Select the app launcher on the top left of the screen.

   [![Screenshot showing Microsoft 365 admin center.](https://learn.microsoft.com/en-us/microsoft-365/education/guide/images/setup/configure-admin-settings-1-sm.png)](https://learn.microsoft.com/en-us/microsoft-365/education/guide/images/setup/configure-admin-settings-1-sm.png#lightbox)
3. In the menu, select **Admin** and then select **Show all**. All your Admin Centers are now in view on the bottom left.

   [![Screenshot showing various Microsoft 365 admin centers.](https://learn.microsoft.com/en-us/microsoft-365/education/guide/images/setup/configure-admin-settings-2-sm.png)](https://learn.microsoft.com/en-us/microsoft-365/education/guide/images/setup/configure-admin-settings-2.png#lightbox)

You can now configure your settings in each Admin Center.

## Security Center

Education organizations are the #1 cyber-security target in all industries. Security for faculty, teachers, and students should be a primary goal for every organization, emphasizing data, devices, access, and Copilot AI settings.

[![Screenshot showing admin center for security.](https://learn.microsoft.com/en-us/microsoft-365/education/guide/images/setup/configure-admin-settings-3-sm.png)](https://learn.microsoft.com/en-us/microsoft-365/education/guide/images/setup/configure-admin-settings-3.png#lightbox)

## Microsoft Purview portal

In the [Microsoft Purview portal](https://learn.microsoft.com/en-us/purview/purview-compliance-portal), you can adjust privacy and compliance with considerations for Family Education Rights and Privacy Act \(FERPA\) \(US\) and General Data Protection Regulation \(GDPR\) \(EU\). You can also use auditing and reporting capabilities to evaluate compliance status.

[![Screenshot showing admin center for Microsoft Purview.](https://learn.microsoft.com/en-us/microsoft-365/education/guide/images/setup/configure-admin-settings-33.png)](https://learn.microsoft.com/en-us/microsoft-365/education/guide/images/setup/configure-admin-settings-33.png#lightbox)

## Microsoft Entra ID

Education organizations can use Microsoft Entra ID to grant/deny access to users and managing administrative units and security groups for segmentation that can be included in features like information barriers. Use the Microsoft Entra admin center to manage identities, permissions, and network access.

[![Screenshot showing admin center for Microsoft Entra ID.](https://learn.microsoft.com/en-us/microsoft-365/education/guide/images/setup/configure-admin-settings-4-sm.png)](https://learn.microsoft.com/en-us/microsoft-365/education/guide/images/setup/configure-admin-settings-4-sm.png#lightbox)

## Exchange

In the Exchange admin center, you can manage advanced email settings, such as quarantine, encryption, and mail flow rules.

You can use Exchange addresses to allow segregation of teachers and students based on your organizations strategy in conjunction with information barriers.

[![Screenshot showing admin center for Exchange.](https://learn.microsoft.com/en-us/microsoft-365/education/guide/images/setup/configure-admin-settings-5-sm.png)](https://learn.microsoft.com/en-us/microsoft-365/education/guide/images/setup/configure-admin-settings-5-sm.png#lightbox)

## SharePoint

SharePoint works as the file storage solution in conjunction with Microsoft Teams Classroom and Microsoft Education Assignments. Additionally, OneDrive allows users in education organizations a location for personal and shared files.

[![Screenshot showing admin center for SharePoint.](https://learn.microsoft.com/en-us/microsoft-365/education/guide/images/setup/configure-admin-settings-6-sm.png)](https://learn.microsoft.com/en-us/microsoft-365/education/guide/images/setup/configure-admin-settings-6-sm.png#lightbox)

## Microsoft Teams

Microsoft Teams is a platform for classroom engagement and uses tenant services to provide secure access and management of education classes.

[![Screenshot showing admin center for Microsoft Teams.](https://learn.microsoft.com/en-us/microsoft-365/education/guide/images/setup/configure-admin-settings-7.png)](https://learn.microsoft.com/en-us/microsoft-365/education/guide/images/setup/configure-admin-settings-7-sm.png#lightbox)

## Other admin centers

You can select **All admin centers** to configure other admin centers as well.
