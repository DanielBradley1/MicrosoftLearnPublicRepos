# Step 7 - License users

In order for users to use any Microsoft 365 services, their accounts must be licensed. There are three ways to license users:

- Assign licenses to individual users in Microsoft 365 Admin Center
- Assign licenses to groups in Microsoft 365 Admin Center

[Microsoft 365 Education Plans](https://cdn-dynmedia-1.microsoft.com/is/content/microsoftcorp/microsoft/final/en-us/microsoft-product-and-services/microsoft-education/downloadables/EDU-Microsoft-365-Plan-Comparison-Table.pdf)

## Assign licenses to individual users in Microsoft Entra admin center

To assign a license to an individual user in the [Microsoft Entra admin center](https://entra.microsoft.com/):

1. Sign in to the Microsoft Entra admin center with a minimum of a license administrator role.
2. Browse to **Identity > Billing > License**.
3. Select the name of the license plan you want to assign to the user.
4. After you select the license plan, select **Assign**.
5. On the **Assign** page, select **Users and groups**, and then search for and select the user you're assigning the license.
6. Select **Assignment options**, make sure you have the appropriate license options turned on, and then select OK. The **Assign license** page updates to show that a user is selected and that the assignments are configured.
7. Select **Assign**.

For more information, see [Assign a license to a user](https://learn.microsoft.com/en-us/entra/fundamentals/license-users-groups#to-assign-a-license-to-a-user).

## Assign a license to groups in Microsoft Entra admin center

To assign licenses to groups in the [Microsoft Entra admin center](https://entra.microsoft.com/):

1. Sign in to the Microsoft Entra admin center with a minimum of a license administrator role.
2. Browse to **Identity > Billing > License**.
3. Select the name of the license plan you want to assign to the group.
4. On the Product page, select **Assign.**
5. On the **Assign** page, select **Users and groups**, and then search for and select the user you're assigning the license.
6. Select **Assignment options**, make sure you have the appropriate license options turned on, and then select **OK**.
7. Select **Assign**.

Note

For education scenarios:

- Organizations can create teacher or student security groups that can be used to control the license assignments or removal.

For more information, see [Assign a license to a group](https://learn.microsoft.com/en-us/entra/fundamentals/license-users-groups#to-assign-a-license-to-a-group)
