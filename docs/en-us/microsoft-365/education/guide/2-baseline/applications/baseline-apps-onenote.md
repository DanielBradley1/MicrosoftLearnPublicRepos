# Set Up OneNote Class Notebooks

OneNote Class Notebook is designed to help teachers save time and be even more efficient with their Class Notebooks. The Class Notebook experience includes powerful tools for page and section distribution, as well as quick review of student work. Every Class Notebook provides:

- A **personal workspace** for every student
- A **content library** for handouts
- A **collaboration space** for lessons and creative activities

The Class Notebook toolbar makes it easy to manage these spaces and streamline classroom workflows. How you access the toolbar depends on which version of OneNote you’re using.

## OneNote for Microsoft 365 \(Desktop\)

The Class Notebook toolbar is now built into the Microsoft 365 desktop version of OneNote. Educators no longer need to download or install the Class Notebook Add-in separately.

To enable the toolbar:

1. Open OneNote \(Microsoft 365\) on your desktop.
2. Navigate to **File > Options**.
3. On the **General** tab, scroll to the **Class Notebook** section at the bottom.
4. Select **Enable Class Notebook**, and then select **OK**.
5. After enabling this setting, the Class Notebook toolbar appears in the ribbon.

## OneNote 2013 or OneNote 2016 \(older desktop versions\)

For older desktop versions of OneNote \(2013 or 2016\), the Class Notebook Add-in is still required to access Class Notebook tools. Download and install the add-in from [Microsoft Support](https://support.microsoft.com/topic/install-class-notebook-add-in-for-onenote-app-8d30736e-39ac-40d4-84a9-d6a0b2138182).

## OneNote on the Web or Mobile

When you open a Class Notebook in OneNote for the web or the OneNote mobile app, the Class Notebook toolbar is available by default. No setup is required.
