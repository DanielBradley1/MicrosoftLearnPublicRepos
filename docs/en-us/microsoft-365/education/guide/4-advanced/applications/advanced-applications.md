# Step 2: Analytics in Microsoft 365 A5 for education

![](https://learn.microsoft.com/en-us/microsoft-365/education/guide/images/sections/advancedsm.png)

This article provides an overview of analytics capabilities available in Microsoft 365 A5 for education, focusing on how advanced analytics tools like Power BI Pro empower educational institutions to make informed, data-driven decisions.

## Requirements

- Microsoft 365 A5 license

## Roles and responsibilities

- IT Admin
- Identity Admin
- OneDrive Admin
- SharePoint Admin
- EXO Admin
- Security Admin
- Compliance Admin

## Power BI Pro

Microsoft Power BI Pro in education is a cloud-based business analytics service that enables educators, administrators, and institutional leaders to visualize data, share insights, and make data-driven decisions. It's included in Microsoft 365 A5 for Education and is also available as a standalone or add-on license for A1 and A3 plans.

**What Power BI Pro offers in education:**

| Capability | Description |
| --- | --- |
| Interactive dashboards | Create and share real-time dashboards to track student performance, attendance, and institutional KPIs. |
| Data collaboration | Share reports securely with faculty, staff, and leadership across departments. |
| Scheduled data refresh | Keep reports up to date with automatic refreshes from connected data sources. |
| Integration with Microsoft 365 | Embed reports in Teams, SharePoint, and Excel for seamless collaboration. |
| Row-level security | Control access to data based on user roles \(for example, teacher vs. principal\). |

**Use cases in education:**

- Student success tracking: Monitor academic progress, dropout risks, and intervention outcomes.
- Operational efficiency: Analyze resource usage, staffing, and budget allocations.
- Learning analytics: Visualize engagement data from learning management system \(LMS\) platforms and digital tools.
- Compliance reporting: Generate reports for FERPA, Title I, and other regulatory requirements.
