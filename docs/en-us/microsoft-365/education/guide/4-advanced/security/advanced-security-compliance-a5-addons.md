# Security A5 addon plans

![](https://learn.microsoft.com/en-us/microsoft-365/education/guide/images/sections/advancedsm.png)

This article outlines the key components of the advanced security capabilities for the Microsoft 365 A5 license for education, including security, compliance, information protection, risk management, and audit features. These capabilities are designed to help educational institutions protect sensitive data, manage compliance requirements, and respond to security threats effectively.

## Requirements

- Microsoft 365 A5 license

## Roles and responsibilities

- IT Admin
- Identity Admin
- OneDrive Admin
- SharePoint Admin
- EXO Admin
- Security Admin
- Compliance Admin

## Microsoft 365 A5 - Security

Microsoft 365 A5 for Education is the most comprehensive suite offered to academic institutions, combining productivity tools with advanced security, compliance, and analytics capabilities. It's designed to help schools and districts protect identities, data, and devices while simplifying IT management.

**Key security products included in Microsoft 365 A5 for education:**

According to both internal and external sources, the following security tools are bundled into the Microsoft 365 A5 for education license:

| Category | Description |
| --- | --- |
| Microsoft Defender for Endpoint \(Plan 2\) | Provides advanced endpoint protection using behavioral sensors, cloud security analytics, and threat intelligence to detect and respond to sophisticated threats |
| Microsoft Defender for Office 365 \(Plan 2\) | Protects against phishing, malware, and business email compromise with features like Safe Links, Safe Attachments, and attack simulation training |
| Microsoft Defender for Identity | Formerly Azure ATP, this tool helps detect identity-based threats across hybrid environments by analyzing user behavior and activities |
| Microsoft Defender for Cloud Apps | Offers visibility and control over cloud app usage, helping to detect unusual behavior and prevent data leaks |
| Microsoft Purview Insider Risk Management | Helps identify and mitigate internal risks by analyzing signals from across Microsoft 365 and third-party services |
| Microsoft Intune for Education | Simplifies device management and policy deployment across student and staff devices, ensuring compliance and security |
| Azure Active Directory Premium P2 \(now Microsoft Entra ID\) | Enables conditional access, identity protection, and privileged identity management to secure user access |
| Advanced Audit and eDiscovery \(Microsoft Purview\) | Supports compliance and legal investigations with long-term audit log retention and advanced search capabilities |
| Microsoft Purview Information Protection | Classifies and protects sensitive data using labels and encryption, integrated across Microsoft 365 apps |
| School Data Sync \(SDS\) | Automates class roster creation and simplifies identity and device management, enhancing security posture |

**Strategic benefits for education:**

- Unified security stack: Replaces up to 26 separate vendor solutions with a single, integrated platform.
- Cost efficiency: Offers enterprise-grade security at education pricing, making it accessible for K-12 and higher education institutions.
- Compliance readiness: Helps meet FERPA, GDPR, and other regulatory requirements through built-in compliance tools.

## Microsoft 365 A5 - Compliance

The A5 Compliance suite is designed to help educational institutions manage regulatory requirements, protect sensitive data, and respond to legal investigations. It builds on the A3 offering by adding advanced compliance, auditing, and data governance capabilities.

**Core compliance capabilities in Microsoft 365 A5 for education:**

| Capability | Description |
| --- | --- |
| Microsoft Purview eDiscovery \(Premium\) | Advanced case management, review sets, and analytics for legal investigations |
| Microsoft Purview Insider Risk Management | Detects and mitigates internal risks like data leaks or policy violations |
| Microsoft Purview Communication Compliance | Monitors communications \(for example, Teams, email\) for policy violations |
| Microsoft Purview Information Protection \(Plan 2\) | Classifies and protects sensitive data across Microsoft 365 |
| Microsoft Purview Data Loss Prevention \(DLP\) | Prevents accidental sharing of sensitive information in email, Teams, and files |
| Endpoint DLP | Extends DLP to Windows 10/11 endpoints to monitor and restrict data movement |
| Communications DLP \(Teams Chat\) | Applies DLP policies to Teams chat messages |
| Litigation Hold | Preserves mailbox content for legal or investigative purposes |
| Advanced Audit \(Microsoft Purview Audit Premium\) | Provides long-term audit log retention and access to crucial forensic data |
| Customer Lockbox | Requires explicit approval before Microsoft engineers can access your content |
| Privileged Access Management | Limits access to high-risk tasks and enforces just-in-time access |
| Microsoft Purview Records Management | Automates retention and deletion policies for regulatory compliance |

**Strategic benefits for education institutions:**

- Regulatory readiness: Supports FERPA, GDPR, and other education-specific compliance mandates
- Data governance: Helps manage lifecycle and access to sensitive student and faculty data
- Risk mitigation: Detects insider threats and enforces communication policies across platforms
- Legal preparedness: Enables fast, defensible responses to legal holds and investigations

## Microsoft 365 A5 - Information Protection and Governance

**What Is Microsoft 365 A5 Information Protection and Governance?**

These features of the Microsoft Purview platform are designed to help educational institutions classify, protect, retain, and govern sensitive data across Microsoft 365 services. They ensure compliance with regulatory requirements like FERPA, GDPR, and HIPAA while enabling secure collaboration in K-12 and higher education environments.

**Core capabilities included in A5 for education:**

| Capability | Description |
| --- | --- |
| Microsoft Purview Information Protection \(Plan 2\) | Enables manual and automatic sensitivity labeling across Microsoft 365 apps, Teams, SharePoint, and OneDrive. Supports auto-labeling based on content inspection |
| Microsoft Purview Data Lifecycle Management | Automates retention and deletion policies for emails, documents, and Teams messages. Helps manage the lifecycle of student and faculty data |
| Microsoft Purview Records Management | Provides advanced capabilities to declare records, apply retention labels, and ensure immutability for compliance |
| Microsoft Purview Data Loss Prevention \(DLP\) | Monitors and prevents accidental sharing of sensitive data across Exchange, Teams, SharePoint, and endpoints |
| Microsoft Purview Communication Compliance | Detects inappropriate or non-compliant communications in Teams, Exchange, and Yammer |
| Microsoft Purview Insider Risk Management | Identifies risky user behavior such as data exfiltration or policy violations |
| Microsoft Purview Audit \(Premium\) | Offers long-term audit log retention and access to critical forensic data for investigations |
| Microsoft Purview eDiscovery \(Premium\) | Supports legal holds, review sets, and advanced case management for legal and HR investigations |

**Strategic benefits for education institutions:**

- Unified data governance: Replace fragmented tools with a single platform that spans all Microsoft 365 services
- Regulatory compliance: Built-in support for FERPA, GDPR, and other education-specific mandates
- Risk reduction: Proactively detect and mitigate insider threats and data leaks
- Operational efficiency: Automate retention, labeling, and classification to reduce manual overhead

## Microsoft 365 A5 - Insider Risk Management

Microsoft Purview Insider Risk Management helps educational institutions detect, investigate, and respond to risky user activities that could lead to data leaks, policy violations, or insider threats. It uses machine learning and behavioral analytics to surface high-risk activities while protecting user privacy.

**Capabilities included in A5 for education:**

| Feature | Description |
| --- | --- |
| Risk policy templates | Prebuilt templates for scenarios like data leaks, data theft by departing users, and security policy violations |
| HR connector Integration | Imports resignation or termination data to trigger risk policies for departing users |
| DLP integration | Connects with Microsoft Purview Data Loss Prevention to trigger alerts based on high-severity DLP incidents |
| Privacy controls | Pseudonymizes user identities during investigations to protect privacy |
| Alert management | Centralized dashboard for triaging and investigating insider risk alerts |
| Automated remediation | Supports actions like user education, policy reminders, or escalation to security teams |

**Strategic benefits for education institutions:**

- Protect Student and Faculty Data: Detects unauthorized access or sharing of sensitive information like student records or research data.
- Support Compliance: Helps meet FERPA, GDPR, and other education-specific regulatory requirements.
- Reduce Investigation Time: Automates detection and prioritization of high-risk activities, reducing manual effort.
- Enable Responsible AI Use: Supports governance frameworks for AI tools like Copilot in education settings.

## Microsoft 365 A5 - eDiscovery and Audit

**What Are eDiscovery and Audit in Microsoft 365 A5 for Education?**

These capabilities are part of the Microsoft Purview compliance suite and are designed to help educational institutions manage legal investigations, regulatory compliance, and internal audits. They provide tools to search, preserve, analyze, and export content across Microsoft 365 services.

**Core capabilities included in A5 for education:**

| Capability | Description |
| --- | --- |
| Microsoft Purview eDiscovery \(Standard\) | Enables content search, legal hold, and export of data from Exchange, SharePoint, OneDrive, and Teams |
| Microsoft Purview eDiscovery \(Premium\) | Adds advanced case management, review sets, analytics, and machine learning to streamline legal investigations |
| Microsoft Purview Audit \(Standard\) | Provides basic audit logging for user and admin activities across Microsoft 365 |
| Microsoft Purview Audit \(Premium\) | Offers long-term audit log retention \(up to one year\), access to crucial forensic data, and advanced filtering for investigations |
| Litigation Hold | Preserves mailbox content to meet legal or regulatory obligations |
| Content Search | Allows administrators to search across mailboxes, SharePoint sites, and Teams for compliance or investigative purposes |
| Supervisory Review | Enables monitoring of employee communications for compliance with internal policies |

**Strategic benefits for education institutions:**

- Legal readiness: Supports defensible eDiscovery processes for FERPA, Title IX, and other education-related investigations
- Data transparency: Enables visibility into user and admin actions across Microsoft 365 services
- Risk mitigation: Helps identify and respond to suspicious or non-compliant behavior quickly
- Cost efficiency: Consolidates multiple compliance tools into a single platform, reducing the need for third-party solutions
