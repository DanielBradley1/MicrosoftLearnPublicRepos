# Microsoft 365 Education licenses - Microsoft 365 and Office 365 A3

This page provides an overview of the features included specifically in the Microsoft Education A3 \(standard\) license. The A3 license also includes the features in the [A1 \(baseline\)](https://learn.microsoft.com/en-us/microsoft-365/education/guide/0-start-baseline/baseline-license) license, which aren't included here. For a list of features available in all education licenses, see [Microsoft 365 Education licenses](https://learn.microsoft.com/en-us/microsoft-365/education/guide/0-start/all-license).
