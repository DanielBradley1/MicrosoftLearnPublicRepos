# Microsoft Education Solution Guide Standard section delivery sequence

The sequence that you follow is Baseline -> Standard -> Advanced phases, depending on your tenant license configuration.

Each phase includes the appropriate or required sections; Tenant Setup, Identity, Applications, Security & Compliance, and Devices.
