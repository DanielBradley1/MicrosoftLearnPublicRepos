# Overview - Tenant setup and deployment guide for Microsoft 365 for education standard configurations

![](https://learn.microsoft.com/en-us/microsoft-365/education/guide/images/sections/standardsm.png)

This article provides a checklist for the continued steps to configure your Standard Microsoft 365 education tenant.

## Required Microsoft products

- Microsoft 365 A3 license

## Define clear guidelines for the retention and disposal of student and staff records

|  | Step |
| --- | --- |
| ☐ | Define the scope of the retention policy by identifying the data types. |
| ☐ | Set retention periods for each category of data. |
| ☐ | Implement the policy using your organization’s data management or IT systems. |
| ☐ | Provide guidelines on proper data handling, retention timelines, and disposal methods. |
| ☐ | Regularly review and update the policy. |

## Configure endpoint devices to automatically establish a secure VPN connection at startup

|  | Step |
| --- | --- |
| ☐ | Configure the VPN solution to support device-wide connections. |
| ☐ | Use group policies or mobile device management \(MDM\) tools to enforce Always On VPN settings. |
| ☐ | Enable split tunneling to optimize bandwidth usage. |
| ☐ | Integrate user authentication protocols. |
| ☐ | Monitor and log VPN usage to ensure compliance and identify potential security issues. |

## Enhance students' and educators' writing and editing capabilities across assignments, research, and communications

|  | Step |
| --- | --- |
| ☐ | Help students improve their writing skills |
| ☐ | Enable plagiarism checker to ensure originality and teach academic integrity. |
| ☐ | Enable students to learn and write in different languages effectively. |
| ☐ | Implement readability analysis. |
| ☐ | Customize feedback options for educators to give personalized guidance. |
