# Overview - Deployment guide for devices - Standard

![](https://learn.microsoft.com/en-us/microsoft-365/education/guide/images/sections/standardsm.png)

This article provides a checklist for the continued steps to configure your Standard Microsoft 365 education tenant.

## Required Microsoft products

- Microsoft 365 A3

## Deployment guide steps

### Standard devices applications and features

|  |  |
| --- | --- |
| ☐ | **Microsoft Intune Remote Help** - Enable IT administrators to securely assist students and staff with troubleshooting and support on managed devices |
| ☐ | **Universal Print** - Simplify and streamlines printing processes by providing a cloud-based solution that integrates seamlessly with devices, enabling secure, efficient, and environmentally friendly printing for students and educators. |
| ☐ | **Take a Test App** - Provides a secure and focused environment for students to complete online assessments. |
| ☐ | **Set up School PCs App** - Simplify the configuration of Windows devices for educational environments. |
| ☐ | **Virtual Desktop Access** - Enable students and educators to securely access institutional resources, applications, and files from any device. |
