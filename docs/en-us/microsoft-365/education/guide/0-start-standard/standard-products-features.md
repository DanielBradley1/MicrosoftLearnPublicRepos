## Threat Protection

### Microsoft Defender Antimalware

Microsoft Defender Antimalware provides real-time protection for educational institutions by detecting and neutralizing malware threats across student and faculty devices, ensuring a secure learning environment.

- [Institute for Advanced Study – Getting Started with Windows Security and Microsoft Defender](https://www.ias.edu/security/getting-started-with-windows-security-windows-defender)
- [CISA – Ensure Antivirus and Anti-Malware Protections Are Active](https://www.cisa.gov/resources-tools/training/ensure-your-os-antivirus-and-anti-malware-protections-are-active)

### Microsoft Defender Firewall

Microsoft Defender Firewall helps educational institutions safeguard their networks by controlling inbound and outbound traffic, reducing the risk of unauthorized access and data breaches.

- [Microsoft Learn – Network Security Protection with Azure Firewall](https://learn.microsoft.com/en-us/shows/microsoft-sentinel-defender-xdr-virtual-ninja-training/network-security-protection-with-azure-firewall-azure-waf-and-azure-ddos)

### Microsoft Defender Exploit Guard

Microsoft Defender Exploit Guard helps educational institutions reduce attack surfaces by blocking behaviors commonly used in malware attacks, such as script-based threats and ransomware.

- [Microsoft Learn – Threat Mitigations in Windows 10](https://learn.microsoft.com/en-us/previous-versions/windows/it-pro/windows-10/security/threat-protection/overview-of-threat-mitigations-in-windows-10)

### Microsoft Defender Credential Guard

Microsoft Defender Credential Guard protects student and staff credentials in education environments by isolating secrets using virtualization-based security, preventing credential theft attacks like Pass-the-Hash.

### BitLocker and BitLocker To Go

BitLocker and BitLocker To Go provide full-disk encryption for devices and removable drives in education, ensuring that sensitive data remains protected even if a device is lost or stolen.

- Microsoft Learn – BitLocker Overview

### Windows Information Protection

Windows Information Protection \(WIP\) helps educational institutions prevent accidental data leaks by separating personal and institutional data on devices and enforcing data protection policies.

### Microsoft Defender for Endpoint Plan 1

Microsoft Defender for Endpoint Plan 1 equips educational institutions with foundational endpoint protection, including next-generation antivirus, attack surface reduction, and centralized management to secure student and faculty devices.
