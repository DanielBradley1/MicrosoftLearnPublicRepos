# Get Data Streamer HackingSTEM samples

The Data Streamer HackingSTEM samples are available through repositories on GitHub. See the [Microsoft Data Streamer HackingSTEM Samples](https://github.com/microsoft/HackingSTEMSamples) repository, which contains samples that demonstrate microcontroller usage patterns for Data Streamer integration.

![Microsoft Data Streamer Electron App GitHub samples.](https://learn.microsoft.com/en-us/microsoft-365/education/data-streamer/media/get-hackingstem-samples/hackingstem-samples-github-repo.png)

## Download the code

To download the samples, go to the [repository](https://github.com/microsoft/HackingSTEMSamples) and select **Clone or download**, then **Download ZIP**. Or, just download from [here](https://github.com/microsoft/HackingSTEMSamples/archive/master.zip).

The zip file will always have the latest samples. You don’t need a GitHub account to download it. When you want to pick up any recent changes/additions, just check back for the latest zip file.

![Microsoft Data Streamer GitHub samples.](https://learn.microsoft.com/en-us/microsoft-365/education/data-streamer/media/get-hackingstem-samples/hackingstem-samples-download.png)

## Unzip the Files

After you download the zip file, right-click on the archive, select **Properties** > check **Unblock** > **Apply**. Then, unzip the archive to a local folder on your machine.
