# Connecting to Apps Via UWP App Service

Data Streamer provides an App Service connection that can be used to stream Comma Separated Values \(SV\) data from Universal Windows Platform \(UWP\) apps and Electron apps \(using UWP middleman app\). Third party apps can provide customized user interaction or connectivity to proprietary devices and the data can be visualized in Microsoft Excel.
