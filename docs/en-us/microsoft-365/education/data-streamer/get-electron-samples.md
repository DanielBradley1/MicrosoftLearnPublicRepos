# Get Data Streamer Electron App Samples

The Data Streamer Electron App Samples are available through repositories on GitHub. See the [Microsoft Data Streamer Samples](https://aka.ms/data-streamer-appservice-sample) repository, which contains samples that demonstrate the Electron App, Packaging Project for distributing through the Microsoft Store, and a Universal Windows Platform \(WP\) App that shows [App Service API](https://learn.microsoft.com/en-us/windows/uwp/launch-resume/app-services) usage patterns for Data Streamer integration.

![Microsoft Data Streamer Electron App GitHub samples.](https://learn.microsoft.com/en-us/microsoft-365/education/data-streamer/media/get-electron-samples/electron-code-samples-github.png)

## Download the code

To download the samples, go to the [repository](https://github.com/Microsoft/DataStreamerSamples) and select **Clone or download**, then **Download ZIP**. Or, just download from [here](https://github.com/microsoft/DataStreamerSamples/archive/master.zip).

The zip file will always have the latest samples. You don’t need a GitHub account to download it. When you want to pick up any recent changes/additions, just check back for the latest zip file.

![Microsoft Data Streamer GitHub samples.](https://learn.microsoft.com/en-us/microsoft-365/education/data-streamer/media/get-electron-samples/electron-samples-download.png)

## Unzip the Files

After you download the zip file, right-click on the archive, select **Properties** > check **Unblock** > **Apply**. Then, unzip the archive to a local folder on your machine. Navigate to the **MiddlemanElectronSampleApp** folder and you’ll see the **AppServiceHost, Electron, and PackagingProject** folders. Inside these you'll find a Visual Studio solution file \(.sln\), which you can open in Visual Studio.
