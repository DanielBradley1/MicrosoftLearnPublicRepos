# Excel Data Streamer Prerequisites

Data Streamer is preinstalled with Microsoft Office 365 in the desktop version of Excel. To make sure you have the latest updates installed, check your version of Office.

## Office Version Check

Data Streamer is currently installed with Excel version 1902 or higher. To check your Office Version, see [About Office: What version of Office am I using?](https://support.office.com/en-gb/article/about-office-what-version-of-office-am-i-using-932788b8-a3ce-44bf-bb09-e334518b8b19).

## Install Office

If you don't have Office installed you can [install Office 365 Education](https://products.office.com/en-us/student/office-in-education).
