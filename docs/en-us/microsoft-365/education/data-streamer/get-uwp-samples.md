# Get Data Streamer UWP App Samples

Data Streamer can receive streaming CSV data from applications using the [App Service API](https://learn.microsoft.com/en-us/windows/uwp/launch-resume/app-services) which is a lightweight inter-app communication mechanism for Windows Applications \(Win32 and Universal Windows Platform \(UWP\)\).

The Data Streamer UWP app samples are available through repositories on GitHub. See the [Microsoft Data Streamer Samples](https://aka.ms/data-streamer-appservice-sample) repository, which contains samples that demonstrate Universal Windows Platform \(UWP\) [App Service API](https://learn.microsoft.com/en-us/windows/uwp/launch-resume/app-services) usage patterns for Data Streamer integration.

![Microsoft Data Streamer GitHub samples repository screenshot.](https://learn.microsoft.com/en-us/microsoft-365/education/data-streamer/media/get-uwp-samples/uwp-code-samples-github.png)

## Download the Code

To download the samples, go to the [repository](https://github.com/Microsoft/DataStreamerSamples) and select **Clone or download**, then **Download ZIP**. Or, just download from [here](https://github.com/microsoft/DataStreamerSamples/archive/master.zip).

The zip file will always have the latest samples. You don’t need a GitHub account to download it. When you want to pick up any recent changes/additions, just check back for the latest zip file.

![Microsoft Data Streamer GitHub samples ZIP download menu.](https://learn.microsoft.com/en-us/microsoft-365/education/data-streamer/media/get-uwp-samples/uwp-samples-download.png)

Note

The UWP samples require Visual Studio 2015 or later and the Windows SDK to open, build, and run. You can get a free copy of Visual Studio Community with support for building UWP apps [here](https://go.microsoft.com/fwlink/p/?LinkID=280676 "Windows development tools downloads").

## Unzip the Files

After you download the zip file, right-click on the archive, select **Properties** > check **Unblock** > **Apply**. Then, unzip the archive to a local folder on your machine. Navigate to the **DataStreamerAppServiceUWPCommSample** folder and you’ll see a Visual Studio solution file \(.sln\), which you can open in Visual Studio.

![Explorer window showing contents of unzipped code sample archive.](https://learn.microsoft.com/en-us/microsoft-365/education/data-streamer/media/get-uwp-samples/uwp-samples-unzipped-archive.png)
