# Welcome to Microsoft Data Streamer Add-in for Excel

Microsoft Data Streamer is a COM Add-in for Microsoft Excel that allows users to stream low latency data into worksheets from connected devices and apps.

## Supported Devices

Supported devices include microcontrollers such as:

- [Arduino Uno and related boards](https://www.arduino.cc/en/Main/Products)
- [micro:bit](https://microbit.org/)
- [Circuit Playground](https://learn.adafruit.com/introducing-circuit-playground)
- [MXChip Azure IoT DevKit](https://microsoft.github.io/azure-iot-developer-kit/v1/)
- any other serial enabled device

## Supported Apps

Universal Windows Platform \(UWP\) Apps and Electron Apps \(using a UWP middleman app\) can connect to Data Streamer via the [App Service API](https://learn.microsoft.com/en-us/windows/uwp/launch-resume/app-services).

## Examples of Data Streamer Usage

Examples of projects developed with Data Streamer include the Hacking STEM portfolio of middle-school and high-school level STEM lessons available at: [aka.ms/hackingstem](https://aka.ms/hackingstem).

## Next steps

Data Streamer is preinstalled with Microsoft Excel. To get started it must first be enabled:

[Enable Microsoft Data Streamer Add-in for Excel](https://learn.microsoft.com/en-us/microsoft-365/education/data-streamer/enable-in-excel).
