# What's new for Microsoft 365 Backup Storage developers

Review recent developer-focused updates for Microsoft 365 Backup Storage. For updates to the Microsoft 365 admin center experience, see [What's new in Microsoft 365 Backup](https://learn.microsoft.com/en-us/microsoft-365/backup/backup-whats-new?view=o365-worldwide).

## Exclusion-unit APIs

**March 31, 2026**

Microsoft Graph Backup Storage adds retrieve and list operations and bulk jobs for excluded Exchange mailboxes, OneDrive drives, and SharePoint sites.

For more information, see the [Microsoft 365 Backup Storage Graph API reference](https://learn.microsoft.com/en-us/graph/api/resources/backuprestoreroot).

## Correct OneDrive restore-session resource

**March 20, 2026**

OneDrive restore examples use the OneDrive for Business restore-session resource.

For more information, see [Create a OneDrive for Business restore session](https://learn.microsoft.com/en-us/graph/api/backuprestoreroot-post-onedriveforbusinessrestoresessions).

## Browse-session resources

**February 6, 2026**

OneDrive and SharePoint browse-session relationships allow applications to browse protected content for granular restore experiences.

For more information, see the [Microsoft 365 Backup Storage Graph API reference](https://learn.microsoft.com/en-us/graph/api/resources/backuprestoreroot).
