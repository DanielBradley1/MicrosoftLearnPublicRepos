# signals resource type

Namespace: microsoft.graph.healthMonitoring

Important

APIs under the `/beta` version in Microsoft Graph are subject to change. Use of these APIs in production applications is not supported. To determine whether an API is available in v1.0, use the **Version** selector.

Represents a collection of signals that are used in the generation of an [alert](https://learn.microsoft.com/en-us/graph/api/resources/healthmonitoring-alert?view=graph-rest-beta) in Microsoft Entra Health.

This resource is an open type that allows additional properties beyond those documented here.

Inherits from [healthMonitoringDictionary](https://learn.microsoft.com/en-us/graph/api/resources/healthmonitoring-healthmonitoringdictionary?view=graph-rest-beta).
