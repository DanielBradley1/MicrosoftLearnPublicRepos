# placeMode resource type

Namespace: microsoft.graph

Represents an abstract base type for modes of [desk](https://learn.microsoft.com/en-us/graph/api/resources/desk?view=graph-rest-1.0) and [workspace](https://learn.microsoft.com/en-us/graph/api/resources/workspace?view=graph-rest-1.0) objects.

Base type of [assignedPlaceMode](https://learn.microsoft.com/en-us/graph/api/resources/assignedplacemode?view=graph-rest-1.0), [dropInPlaceMode](https://learn.microsoft.com/en-us/graph/api/resources/dropinplacemode?view=graph-rest-1.0), [reservablePlaceMode](https://learn.microsoft.com/en-us/graph/api/resources/reservableplacemode?view=graph-rest-1.0), and [unavailablePlaceMode](https://learn.microsoft.com/en-us/graph/api/resources/unavailableplacemode?view=graph-rest-1.0).
