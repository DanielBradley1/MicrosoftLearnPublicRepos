# teleconferenceDeviceScreenSharingQuality resource type

Namespace: microsoft.graph

Represents video teleconferencing device screen-sharing quality data.

## Properties

The **teleconferenceDeviceScreenSharingQuality** inherits all the properties from [teleconferenceDeviceVideoQuality](https://learn.microsoft.com/en-us/graph/api/resources/teleconferencedevicevideoquality?view=graph-rest-1.0).
