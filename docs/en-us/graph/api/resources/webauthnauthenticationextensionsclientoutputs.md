# webauthnAuthenticationExtensionsClientOutputs resource type

Namespace: microsoft.graph

Contains the output values returned by the client for requested WebAuthn extensions. This is an open type that allows for additional properties based on the specific extensions used. This complex type is the type for the **clientExtensionResults** property of the [webauthnPublicKeyCredential](https://learn.microsoft.com/en-us/graph/api/resources/webauthnpublickeycredential?view=graph-rest-1.0) resource.

This resource is an open type.

## Properties

None.
