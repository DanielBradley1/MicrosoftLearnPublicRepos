# workbookChartFill resource type

Namespace: microsoft.graph

Represents the fill formatting for a chart element.

## Methods

| Method | Return Type | Description |
| :--- | :--- | :--- |
| [Set clear fill](https://learn.microsoft.com/en-us/graph/api/chartfill-clear?view=graph-rest-1.0) | None | Clear the fill color of a chart element. |
| [Set solid fill](https://learn.microsoft.com/en-us/graph/api/chartfill-setsolidcolor?view=graph-rest-1.0) | None | Sets the fill formatting of a chart element to a uniform color. |
