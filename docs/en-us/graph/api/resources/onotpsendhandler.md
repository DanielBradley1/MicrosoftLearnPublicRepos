# onOtpSendHandler resource type

Namespace: microsoft.graph

Used to configure what to invoke if the onEmailOTPSend event resolves to this listener. This base class serves as a generic OTP event handler used for both email and SMS OTP messages. This object is an abstract type from which the [onOtpSendCustomExtensionHandler resource type](https://learn.microsoft.com/en-us/graph/api/resources/onotpsendcustomextensionhandler?view=graph-rest-1.0) inherits.
