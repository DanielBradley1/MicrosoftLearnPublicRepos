# investigationSession resource type

Namespace: microsoft.graph

Represents an execution of a security playbook against typed inputs. Create a session to start asynchronous investigation work, and read its **status** and **statusDetail** to monitor progress. Inputs belong to the session, and outputs are session-owned stored files.

Inherits from [entity](https://learn.microsoft.com/en-us/graph/api/resources/entity?view=graph-rest-beta).

## Properties

| Property | Type | Description |
| :--- | :--- | :--- |
| createdDateTime | DateTimeOffset | The UTC date and time when the resource was created, in ISO 8601 format. Read-only. |
| displayName | String | The session name generated by the service. Read-only. |
| id | String | The unique, read-only identifier of the resource. |
| initiatedBy | [investigationIdentitySet](https://learn.microsoft.com/en-us/graph/api/resources/investigationidentityset?view=graph-rest-beta) | The initiating principals recorded by the service, when available. Read-only. This property doesn't select an execution identity. |
| lastModifiedDateTime | DateTimeOffset | The UTC date and time when the resource was last updated, in ISO 8601 format. Read-only. |
| status | longRunningOperationStatus | The service-computed processing status. The possible values are: `notStarted`, `running`, `succeeded`, `failed`, `unknownFutureValue`. A canceled execution has `failed` status and `stopped` **statusDetail**. A request for input has `running` status and `waitingForInput` **statusDetail**. Read-only. Supports `$filter` \(`eq`, `or`, `in`\) when listing sessions. |
| statusDetail | String | Additional processing detail, including `waitingForInput` or `stopped`, when the status alone doesn't describe the source lifecycle. Read-only. Doesn't support `$filter`. For the session lifecycle combinations, see [Get agentic session](https://learn.microsoft.com/en-us/graph/api/investigationsession-get?view=graph-rest-beta#session-status-and-status-details). |
| tags | String collection | The service-generated tags for the session. Read-only. Can't be supplied when creating a session. |

## Relationships

| Relationship | Type | Description |
| :--- | :--- | :--- |
| agentRuns | [agentRun](https://learn.microsoft.com/en-us/graph/api/resources/agentrun?view=graph-rest-beta) collection | The read-only agent runs owned by this session. Supports list and keyed GET with `$select` and server-driven paging. |
| inputs | [investigationInput](https://learn.microsoft.com/en-us/graph/api/resources/investigationinput?view=graph-rest-beta) collection | The input references contained by the session. Required inline array on session creation; it can be empty if the playbook permits it. Each new input accepts only **kind** and **value**. After creation, supports only list and keyed GET with `$select` and server-driven paging. |
| outputs | [investigationOutput](https://learn.microsoft.com/en-us/graph/api/resources/investigationoutput?view=graph-rest-beta) collection | The read-only stored-file outputs owned by this session. Supports list and keyed GET with `$select`, server-driven paging, and authenticated content downloads. |
| playbookDefinition | [playbookDefinition](https://learn.microsoft.com/en-us/graph/api/resources/playbookdefinition?view=graph-rest-beta) | The required reference to an existing catalog definition, selected once by **playbookDefinition@odata.bind** on creation. Supports GET with `$select`. Deep insert, rebinding, `$ref` writes, and `$expand` aren't supported. |
