# mediaPrompt resource type

Namespace: microsoft.graph

This resource type contains information about the audio file to be played and other additional settings.

## Properties

| Property | Type | Description |
| :--- | :--- | :--- |
| mediaInfo | [mediaInfo](https://learn.microsoft.com/en-us/graph/api/resources/mediainfo?view=graph-rest-1.0) | The media information |
