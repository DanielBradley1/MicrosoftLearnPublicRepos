# restoreAction resource type

Namespace: microsoft.graph

The presence of the **restoreAction** resource on an [**itemActivity**](https://learn.microsoft.com/en-us/graph/api/resources/itemactivity?view=graph-rest-1.0) indicates that the activity restored an item.

**Note**: This resource is currently empty. In the future, it might be populated with additional properties.

> **Note:** Item activity records are currently only available on SharePoint and OneDrive for Business.

## Properties

None. This facet is a null or not-null value and contains no properties.
