# onTokenIssuanceStartHandler resource type

Namespace: microsoft.graph

Handler for the event when a token is about to be issued to your application. This is an abstract type from which the [onTokenIssuanceStartCustomExtensionHandler](https://learn.microsoft.com/en-us/graph/api/resources/ontokenissuancestartcustomextensionhandler?view=graph-rest-1.0) resource type is derived.
