# removeAccessApplyAction resource type

Namespace: microsoft.graph

In an [accessReviewScheduleDefinition](https://learn.microsoft.com/en-us/graph/api/resources/accessreviewscheduledefinition?view=graph-rest-1.0), the **applyActions** property of [accessReviewScheduleSettings](https://learn.microsoft.com/en-us/graph/api/resources/accessreviewschedulesettings?view=graph-rest-1.0) uses **removeAccessApplyAction** as the default action to remove access from a resource for denied reviewers.

Inherits from [accessReviewApplyAction](https://learn.microsoft.com/en-us/graph/api/resources/accessreviewapplyaction?view=graph-rest-1.0).
