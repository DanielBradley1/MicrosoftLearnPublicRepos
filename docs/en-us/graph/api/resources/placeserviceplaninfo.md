# placeServicePlanInfo resource type

Namespace: microsoft.graph

Represents details of a service plan associated with a place.

This type is returned by the **servicePlans** property of the [desk](https://learn.microsoft.com/en-us/graph/api/resources/desk?view=graph-rest-1.0) resource.

## Properties

| Property | Type | Description |
| :--- | :--- | :--- |
| servicePlanId | String | The service plan identifier. |

The following JSON representation shows the resource type.

}
