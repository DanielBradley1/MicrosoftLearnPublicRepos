# contentBase resource type

Namespace: microsoft.graph

Abstract base type representing the actual content, text, or binary\) being processed.

Use [textContent](https://learn.microsoft.com/en-us/graph/api/resources/textcontent?view=graph-rest-1.0) for text or [binaryContent](https://learn.microsoft.com/en-us/graph/api/resources/binarycontent?view=graph-rest-1.0) binary content.

> **Note:** This abstract type won't be instantiated directly.

## Properties

None.

## Relationships

None.
