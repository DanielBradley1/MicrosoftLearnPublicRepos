# textContent resource type

Namespace: microsoft.graph

Represents content provided as a plain text string.

Inherits from [contentBase](https://learn.microsoft.com/en-us/graph/api/resources/contentbase?view=graph-rest-1.0).

## Properties

| Property | Type | Description |
| :--- | :--- | :--- |
| data | String | The text content data. Inherits properties from [contentBase](https://learn.microsoft.com/en-us/graph/api/resources/contentbase?view=graph-rest-1.0). |

## Relationships

None.
