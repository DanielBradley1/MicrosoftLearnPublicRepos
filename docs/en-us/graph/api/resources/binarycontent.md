# binaryContent resource type

Namespace: microsoft.graph

Represents content provided as a Base64-encoded binary data stream.

Inherits from [contentBase](https://learn.microsoft.com/en-us/graph/api/resources/contentbase?view=graph-rest-1.0).

## Properties

| Property | Type | Description |
| :--- | :--- | :--- |
| data | Binary | The binary content, encoded as a Base64 string. Inherited from [contentBase](https://learn.microsoft.com/en-us/graph/api/resources/contentbase?view=graph-rest-1.0). |

## Relationships

None.
