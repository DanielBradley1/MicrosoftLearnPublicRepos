# educationAssignmentClassRecipient resource type

Namespace: microsoft.graph

Resource type that is used inside the [assignment.assignTo](https://learn.microsoft.com/en-us/graph/api/resources/educationassignment?view=graph-rest-1.0) property.

When set to class recipient, every student in the class will receive a submission object when the assignment is published.

This resource is a subclass of [educationAssignmentRecipient](https://learn.microsoft.com/en-us/graph/api/resources/educationassignmentrecipient?view=graph-rest-1.0).
