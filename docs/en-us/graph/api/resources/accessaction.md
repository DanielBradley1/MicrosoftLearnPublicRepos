# accessAction resource type

Namespace: microsoft.graph

The presence of the **accessAction** resource on an [**itemActivity**](https://learn.microsoft.com/en-us/graph/api/resources/itemactivity?view=graph-rest-1.0) indicates that the activity accessed an item.

> **Note:** Access activity records are currently only available on SharePoint and OneDrive for Business.

## Properties

This resource type has no properties.
