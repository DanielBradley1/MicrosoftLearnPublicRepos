# customExtensionBehaviorOnError resource type

Namespace: microsoft.graph

Represents the configuration for the behavior of the call when a custom authentication extension returns an error.

This object is an abstract type from which the [fallbackToMicrosoftProviderOnError](https://learn.microsoft.com/en-us/graph/api/resources/fallbacktomicrosoftprovideronerror?view=graph-rest-1.0) inherits.
