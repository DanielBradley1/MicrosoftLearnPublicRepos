# dataSecurityAndGovernance resource type

Namespace: microsoft.graph

Abstract base type representing the entry point for Microsoft Purview data security and governance features. The following resources inherit from this type:

- [userDataSecurityAndGovernance](https://learn.microsoft.com/en-us/graph/api/resources/userdatasecurityandgovernance?view=graph-rest-1.0)
- [tenantDataSecurityAndGovernance](https://learn.microsoft.com/en-us/graph/api/resources/tenantdatasecurityandgovernance?view=graph-rest-1.0)

## Methods

None.
