# agreementFileData resource type

Namespace: microsoft.graph

Represents a Microsoft Entra terms of use [agreement](https://learn.microsoft.com/en-us/graph/api/resources/agreement?view=graph-rest-1.0) file.

## Properties

| Property | Type | Description |
| :--- | :--- | :--- |
| data | Binary | Data that represents the terms of use PDF document. Read-only. |

## Relationships

None.
