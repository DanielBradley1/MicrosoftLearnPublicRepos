# targetApplicationOwners resource type

Namespace: microsoft.graph

Used in an access package assignment policy, this type inherits from [subjectSet](https://learn.microsoft.com/en-us/graph/api/resources/subjectset?view=graph-rest-1.0) and indicates that application owners may request an access package on behalf of that application.

## Properties

None.

## Relationships
