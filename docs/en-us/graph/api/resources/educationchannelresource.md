# educationChannelResource resource type

Namespace: microsoft.graph

A subclass of [educationResource](https://learn.microsoft.com/en-us/graph/api/resources/educationresource?view=graph-rest-1.0) that represents a Microsoft Teams channel in the class. Only channels from the same class can be attached to the module.

## Properties

| Property | Type | Description |
| :--- | :--- | :--- |
| url | String | URL of the channel resource. |

## Relationships

None.
