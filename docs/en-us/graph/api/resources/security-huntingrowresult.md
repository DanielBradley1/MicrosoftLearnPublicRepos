# huntingRowResult resource type

Namespace: microsoft.graph.security

Represents a row of the [results](https://learn.microsoft.com/en-us/graph/api/resources/security-huntingqueryresults?view=graph-rest-1.0) from running an [advanced hunting query](https://learn.microsoft.com/en-us/graph/api/security-security-runhuntingquery?view=graph-rest-1.0).

The content of the results is depended on the submitted KQL query, see [KQL quick reference](https://learn.microsoft.com/en-us/azure/data-explorer/kql-quick-reference).
