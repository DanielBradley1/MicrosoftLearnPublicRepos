# error resource type

Namespace: microsoft.graph

Represents an error that occurred during a cross-tenant migration.

## Properties

| Property | Type | Description |
| :--- | :--- | :--- |
| code | String | The error code. |
| message | String | The message for the error. |

## Relationships

None.
