# updatableAssetEnrollment resource type \(deprecated\)

Namespace: microsoft.graph.windowsUpdates

Important

APIs under the `/beta` version in Microsoft Graph are subject to change. Use of these APIs in production applications is not supported. To determine whether an API is available in v1.0, use the **Version** selector.

Caution

The **updatableAssetEnrollment** resource is deprecated and stopped returning data on July 1, 2024. Going forward, use the [updateManagementEnrollment](https://learn.microsoft.com/en-us/graph/api/resources/windowsupdates-updatemanagementenrollment?view=graph-rest-beta) resource instead.

An abstract type that represents an enrollment into an area of Windows Autopatch.

Base type of [updateManagementEnrollment](https://learn.microsoft.com/en-us/graph/api/resources/windowsupdates-updatemanagementenrollment?view=graph-rest-beta).
