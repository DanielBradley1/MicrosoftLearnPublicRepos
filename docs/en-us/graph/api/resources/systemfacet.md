# system facet

Namespace: microsoft.graph

The **system** facet indicates that the object is managed by the system for its own operation. Most apps should ignore items that have a System facet.

> **Note**: While this facet is empty today, in future API revisions the facet may be populated with additional properties.

## JSON representation

```json
{
}
```

## Properties

None. This facet is a null or not-null value and contains no properties.
