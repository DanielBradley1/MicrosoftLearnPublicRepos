# policyLocationApplication resource type

Namespace: microsoft.graph

Represents a specific application as a location for data protection policy scoping.

Inherits from [policyLocation](https://learn.microsoft.com/en-us/graph/api/resources/policylocation?view=graph-rest-1.0).

## Properties

| Property | Type | Description |
| :--- | :--- | :--- |
| value | String | The actual value representing the location \(for example, "83ef198a-0396-4893-9d4f-d36efbffcaaa"\). Inherited from [policyLocation](https://learn.microsoft.com/en-us/graph/api/resources/policylocation?view=graph-rest-1.0). |

## Relationships

None.
