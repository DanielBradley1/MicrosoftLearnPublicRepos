# fileStorageContainerCustomPropertyDictionary resource type

Namespace: microsoft.graph

Represents a [dictionary](https://github.com/microsoft/api-guidelines/blob/vNext/graph/patterns/dictionary.md) that stores the custom properties of a [fileStorageContainer](https://learn.microsoft.com/en-us/graph/api/resources/filestoragecontainer?view=graph-rest-1.0) in key/value pairs.

Each custom property consists of keys \(custom property names\) and [fileStorageContainerCustomPropertyValue](https://learn.microsoft.com/en-us/graph/api/resources/filestoragecontainercustompropertyvalue?view=graph-rest-1.0) values \(custom property values\).

## Properties

None.
