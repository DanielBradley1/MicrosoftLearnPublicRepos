# alertCustomDetails resource type

Namespace: microsoft.graph.security

Contains custom key-value detail pairs to include in an alert generated by a custom detection rule. This object is configured in the **customDetails** property of an [alertTemplate](https://learn.microsoft.com/en-us/graph/api/resources/security-alerttemplate?view=graph-rest-1.0).

This resource is an open type that allows more values to be returned than defined.

## Properties

None.
