# alertCustomDetails resource type

Namespace: microsoft.graph.security

Important

APIs under the `/beta` version in Microsoft Graph are subject to change. Use of these APIs in production applications is not supported. To determine whether an API is available in v1.0, use the **Version** selector.

Contains custom key-value detail pairs to include in an alert generated by a custom detection rule. This object is configured in the **customDetails** property of an [alertTemplate](https://learn.microsoft.com/en-us/graph/api/resources/security-alerttemplate?view=graph-rest-beta).

This resource is an open type that allows more values to be returned than defined.
