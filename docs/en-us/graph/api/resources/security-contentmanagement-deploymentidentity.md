# deploymentIdentity resource type

Namespace: microsoft.graph.security.contentManagement

Important

APIs under the `/beta` version in Microsoft Graph are subject to change. Use of these APIs in production applications is not supported. To determine whether an API is available in v1.0, use the **Version** selector.

Represents the **deploymentIdentity** property or connect action parameter of a [contentManagementRepository](https://learn.microsoft.com/en-us/graph/api/resources/security-contentmanagement-contentmanagementrepository?view=graph-rest-beta). This type is abstract and cannot be instantiated directly. Use a [servicePrincipalDeploymentIdentity](https://learn.microsoft.com/en-us/graph/api/resources/security-contentmanagement-serviceprincipaldeploymentidentity?view=graph-rest-beta) or [managedIdentityDeploymentIdentity](https://learn.microsoft.com/en-us/graph/api/resources/security-contentmanagement-managedidentitydeploymentidentity?view=graph-rest-beta) and distinguish derived types with `@odata.type`. This is an abstract type.
