# callMediaState resource type

Namespace: microsoft.graph

Represents the media state for a [call](https://learn.microsoft.com/en-us/graph/api/resources/call?view=graph-rest-1.0).

## Properties

| Property | Type | Description |
| :--- | :--- | :--- |
| audio | mediaState | The audio media state. The possible values are: `active`, `inactive`, `unknownFutureValue`. |

## JSON representation

The following JSON representation shows the resource type.

```json
{
  "audio": "active | inactive",
}
```
