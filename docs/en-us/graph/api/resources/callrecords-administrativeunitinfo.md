# administrativeUnitInfo resource type

Namespace: microsoft.graph.callRecords

Represents the administrative units associated with a [participant object](https://learn.microsoft.com/en-us/graph/api/resources/callrecords-participantbase?view=graph-rest-1.0).

## Properties

| Property | Type | Description |
| :--- | :--- | --- |
| id | String | Unique identifier for the administrative unit. |

## Methods

None.

## JSON representation

The following JSON representation shows the resource type.

```json
{
  "id": "String (identifier)"
}
```
