# stringKeyStringValuePair resource type

Namespace: microsoft.graph

Represents a key-value pair where the key is a string and the value is a string. This object is configured in the **metadata** property of [synchronizationRule](https://learn.microsoft.com/en-us/graph/api/resources/synchronization-synchronizationrule?view=graph-rest-1.0).

## Properties

| Property | Type | Description |
| :--- | :--- | :--- |
| key | String | Key. |
| value | String | Value. |

## JSON representation

The following JSON representation shows the resource type.

```json
{
  "key": "String",
  "value": "String"
}
```
