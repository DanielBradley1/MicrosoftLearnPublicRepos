# dropInPlaceMode resource type

Namespace: microsoft.graph

Indicates that the desk or workspace is a drop-in [place](https://learn.microsoft.com/en-us/graph/api/resources/place?view=graph-rest-1.0); that means it's first come, first served.

These [places](https://learn.microsoft.com/en-us/graph/api/resources/place?view=graph-rest-1.0) are reservable, but can't be booked in advance. The [place](https://learn.microsoft.com/en-us/graph/api/resources/place?view=graph-rest-1.0) is automatically booked for you when you connect your Windows or macOS device to a configured peripheral on the [place](https://learn.microsoft.com/en-us/graph/api/resources/place?view=graph-rest-1.0).
