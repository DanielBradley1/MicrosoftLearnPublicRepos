# educationLinkedAssignmentResource resource type

Namespace: microsoft.graph

A subclass of [educationResource](https://learn.microsoft.com/en-us/graph/api/resources/educationresource?view=graph-rest-1.0) that represents a link to an [educationAssignment](https://learn.microsoft.com/en-us/graph/api/resources/educationassignment?view=graph-rest-1.0). Only assignments from the same class can be attached to the module.

## Properties

| Property | Type | Description |
| :--- | :--- | :--- |
| url | String | URL of the actual assignment. |

## Relationships

None.
