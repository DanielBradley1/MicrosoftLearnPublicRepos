# accessReviewNotificationRecipientScope resource type

Namespace: microsoft.graph

In an [accessReviewScheduleDefinition](https://learn.microsoft.com/en-us/graph/api/resources/accessreviewscheduledefinition?view=graph-rest-1.0), the **additionalNotificationRecipients** property configures [accessReviewNotificationRecipientItem](https://learn.microsoft.com/en-us/graph/api/resources/accessreviewnotificationrecipientitem?view=graph-rest-1.0) objects, and each item's **notificationRecipientScope** property uses **accessReviewNotificationRecipientScope** to define who receives notification emails. It's inherited by [accessReviewNotificationRecipientQueryScope](https://learn.microsoft.com/en-us/graph/api/resources/accessreviewnotificationrecipientqueryscope?view=graph-rest-1.0).
