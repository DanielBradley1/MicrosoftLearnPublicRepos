# meetingInfo resource type

Namespace: microsoft.graph

An abstract class that contains meeting-specific information.

To join an existing meeting, you must either specify the [organizerMeetingInfo](https://learn.microsoft.com/en-us/graph/api/resources/organizermeetinginfo?view=graph-rest-1.0) in combination with the [chatInfo](https://learn.microsoft.com/en-us/graph/api/resources/chatinfo?view=graph-rest-1.0), the [tokenMeetingInfo](https://learn.microsoft.com/en-us/graph/api/resources/tokenmeetinginfo?view=graph-rest-1.0), or the [joinMeetingIdMeetingInfo](https://learn.microsoft.com/en-us/graph/api/resources/joinmeetingidmeetinginfo?view=graph-rest-1.0).

Base type of [organizerMeetingInfo](https://learn.microsoft.com/en-us/graph/api/resources/organizermeetinginfo?view=graph-rest-1.0), [tokenMeetingInfo](https://learn.microsoft.com/en-us/graph/api/resources/tokenmeetinginfo?view=graph-rest-1.0), and [joinMeetingIdMeetingInfo](https://learn.microsoft.com/en-us/graph/api/resources/joinmeetingidmeetinginfo?view=graph-rest-1.0).
