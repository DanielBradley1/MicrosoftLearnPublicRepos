# cancelScope resource type

Namespace: microsoft.graph.identityGovernance

An abstract base type that defines the scope for canceling workflow processing when using the [cancelProcessing](https://learn.microsoft.com/en-us/graph/api/identitygovernance-workflow-cancelprocessing?view=graph-rest-1.0) action. This type can't be instantiated directly; use one of the derived types such as [cancelRunsScope](https://learn.microsoft.com/en-us/graph/api/resources/identitygovernance-cancelrunsscope?view=graph-rest-1.0) instead.

Base type of [cancelRunsScope](https://learn.microsoft.com/en-us/graph/api/resources/identitygovernance-cancelrunsscope?view=graph-rest-1.0).
