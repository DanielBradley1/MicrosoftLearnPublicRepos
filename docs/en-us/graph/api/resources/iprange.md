# ipRange resource type

Namespace: microsoft.graph

An IP range abstract type from which the [iPv4CidrRange](https://learn.microsoft.com/en-us/graph/api/resources/ipv4cidrrange?view=graph-rest-1.0) and [iPv6CidrRange](https://learn.microsoft.com/en-us/graph/api/resources/ipv6cidrrange?view=graph-rest-1.0) resource types for configuring [ipNamedLocation](https://learn.microsoft.com/en-us/graph/api/resources/ipnamedlocation?view=graph-rest-1.0) objects are derived.

The [iPv4CidrRange](https://learn.microsoft.com/en-us/graph/api/resources/ipv4cidrrange?view=graph-rest-1.0) derived type is used to configure IPv4 address ranges while the [iPv6CidrRange](https://learn.microsoft.com/en-us/graph/api/resources/ipv6cidrrange?view=graph-rest-1.0) derived type is used to configure IPv6 address ranges.
