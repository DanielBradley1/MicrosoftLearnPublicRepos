# participantJoiningResponse resource type

Namespace: microsoft.graph

An abstract base class that contains the response to a participant joining notification.

## Derived types

| Type | Description |
| :--- | :--- |
| [acceptJoinResponse](https://learn.microsoft.com/en-us/graph/api/resources/acceptjoinresponse?view=graph-rest-1.0) | Response to accept participant to the call. |
| [rejectJoinResponse](https://learn.microsoft.com/en-us/graph/api/resources/rejectjoinresponse?view=graph-rest-1.0) | Response to reject participant to the call. |
| [inviteNewBotResponse](https://learn.microsoft.com/en-us/graph/api/resources/invitenewbotresponse?view=graph-rest-1.0) | Response to request participant joining notification sent out again as an incoming call notification. |
