# billedUsage resource type

Namespace: microsoft.graph.partners.billing

Note

This API is available for Cloud Solution Provider \(CSP\) partners only to access their billed and unbilled reconciliation data for a tenant. To learn more about the CSP program, see [Microsoft Cloud Solution Provider](https://learn.microsoft.com/en-us/partner-center/csp-overview).

Represents details for billed Azure usage data.

## Methods

| Method | Return type | Description |
| :--- | :--- | :--- |
| [Export](https://learn.microsoft.com/en-us/graph/api/partners-billing-billedusage-export?view=graph-rest-1.0) | [microsoft.graph.partners.billing.operation](https://learn.microsoft.com/en-us/graph/api/resources/partners-billing-operation?view=graph-rest-1.0) | Export the billed Azure usage data. |
