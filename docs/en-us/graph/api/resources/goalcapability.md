# goalCapability resource type

Namespace: microsoft.graph

Important

APIs under the `/beta` version in Microsoft Graph are subject to change. Use of these APIs in production applications is not supported. To determine whether an API is available in v1.0, use the **Version** selector.

The **capabilities** property of the [goal](https://learn.microsoft.com/en-us/graph/api/resources/goal?view=graph-rest-beta) resource uses this type.

Server-computed, read-only capability flags for a [goal](https://learn.microsoft.com/en-us/graph/api/resources/goal?view=graph-rest-beta). Reserved for future use; it currently has no properties.
