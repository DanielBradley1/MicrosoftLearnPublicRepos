# Manage an external tenant with Azure REST API \(Preview\)

**Applies to**: ![Green circle with a white check mark symbol that indicates the following content applies to external tenants.](https://learn.microsoft.com/en-us/entra/external-id/media/common/applies-to-yes.png) External tenants \([learn more](https://learn.microsoft.com/en-us/entra/external-id/tenant-configurations)\)

You can manage your external tenant by using the Azure REST API. Tenant management resources support the following API operations. Each link in the following sections targets the corresponding page in the Azure REST API reference for that operation.

## Tenant Management operations

You can perform tenant management operations for your external tenant by using the following operations:

- [Create or Update](https://learn.microsoft.com/en-us/rest/api/activedirectory/ciam-tenants/create)
- [Delete](https://learn.microsoft.com/en-us/rest/api/activedirectory/ciam-tenants/delete)
- [Get](https://learn.microsoft.com/en-us/rest/api/activedirectory/ciam-tenants/get)
- [List by Resource Group](https://learn.microsoft.com/en-us/rest/api/activedirectory/ciam-tenants/list-by-resource-group)
- [List by Subscription](https://learn.microsoft.com/en-us/rest/api/activedirectory/ciam-tenants/list-by-subscription)
- [Update](https://learn.microsoft.com/en-us/rest/api/activedirectory/ciam-tenants/update)
