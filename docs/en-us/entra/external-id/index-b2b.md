# External ID for business guests documentation

Microsoft Entra External ID is a solution for managing your external identities scenarios, including guest user access \(B2B collaboration\) and customer identity and access management \(CIAM\) for apps. Learn how to use B2B collaboration capabilities to secure and manage workforce collaboration with business guests and partners.
