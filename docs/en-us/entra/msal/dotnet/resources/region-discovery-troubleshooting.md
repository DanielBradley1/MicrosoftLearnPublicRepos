# Region discovery troubleshooting

Microsoft Entra ID has adding support for regional STS \(ESTS-Regional\). Currently only the service to service flow \(client\_credentials / AcquireTokenForClient\) is available via opt-in only to first party apps.

For more details refer to [internal guidance](https://aka.ms/msal/estsr/guidance).
