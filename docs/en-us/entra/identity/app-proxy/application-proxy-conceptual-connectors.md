# Understand Microsoft Entra application proxy connectors

## Overview

Application proxy uses the same connector as Microsoft Entra Private Access, the Microsoft Entra private network connector. For more information, see [Microsoft Entra private network connectors](https://learn.microsoft.com/en-us/entra/global-secure-access/concept-connectors).
