# Application and HR provisioning documentation

Microsoft Entra app provisioning lets you automatically create and manage user identities in your cloud \(SaaS\) apps. Microsoft Entra ID also provides provisioning with cloud-based human resources \(HR\) applications. Learn how to manage and deploy cloud app and HR provisioning with our quickstarts, tutorials, and guidance.
