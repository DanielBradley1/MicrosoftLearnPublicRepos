# Use the Setup Wizard to install Configuration Manager sites

*Applies to: Configuration Manager \(current branch\)*

To install a new Configuration Manager site by using a guided user interface, use the Configuration Manager Setup Wizard \(setup.exe\). The wizard supports installing a primary site or central administration site \(CAS\). You also use the wizard to [upgrade an evaluation installation](https://learn.microsoft.com/en-us/intune/configmgr/core/servers/deploy/install/upgrade-an-evaluation-install-to-a-full-install) of Configuration Manager to a fully licensed installation. When you don't want to use the wizard, you can instead use an [installation script](https://learn.microsoft.com/en-us/intune/configmgr/core/servers/deploy/install/use-a-command-line-to-install-sites) and run an unattended command-line installation.

Install a secondary site from within the Configuration Manager console. Secondary sites don't support a scripted command-line installation.

Before you install a site, be familiar with the details in the following articles:

- [Design a hierarchy of sites](https://learn.microsoft.com/en-us/intune/configmgr/core/plan-design/hierarchy/design-a-hierarchy-of-sites)
- [Site and site system prerequisites](https://learn.microsoft.com/en-us/intune/configmgr/core/plan-design/configs/site-and-site-system-prerequisites)
- [Prepare to install sites](https://learn.microsoft.com/en-us/intune/configmgr/core/servers/deploy/install/prepare-to-install-sites)
- [Prerequisites for installing sites](https://learn.microsoft.com/en-us/intune/configmgr/core/servers/deploy/install/prerequisites-for-installing-sites)
- Assess server readiness with the [Prerequisite Checker](https://learn.microsoft.com/en-us/intune/configmgr/core/servers/deploy/install/prerequisite-checker)
- [Release notes](https://learn.microsoft.com/en-us/intune/configmgr/core/servers/deploy/install/release-notes)
