# Cloud management gateway virtual machine scale set image update for Microsoft Configuration Manager

*Applies to: Configuration Manager \(current branch, versions 2603 and 2509, and versions 2503 and 2409 with update rollup installed\)*

This article describes an update to the cloud management gateway \(CMG\) virtual machine scale set image in Microsoft Configuration Manager.

## Summary of KB37942646

An update is available to resolve the following issue for Configuration Manager customers using the cloud management gateway \(CMG\) component.

The legacy Windows Server 2022 Azure Marketplace images \(offer: `windowsserver`\) that include .NET 6 are being deprecated. Cloud management gateway deployments that use Virtual Machine Scale Sets reference these legacy images.

After the deprecation begins, the legacy images are no longer compliant or supported, and won't receive new OS patch updates via image refresh. Once enforcement begins in early 2027, new CMG deployments and reimaging operations that reference the legacy images fail.

This update transitions the CMG virtual machine scale set to use the new Windows Server 2022 image offer \(`windowsserver2022`\) that doesn't include the deprecated .NET 6 packages. For more information on the deprecation timeline and its effect, see [Breaking change for Window Server 2022 Image Users with .NET 6](https://aka.ms/KB37942646_IMGDep).

Note

This same update is included with the second update rollup for Configuration Manager version 2509 \([KB 37864969](https://learn.microsoft.com/en-us/intune/configmgr/hotfix/2509/37864969)\). A separate out of band hotfix isn't required for version 2509.

### Update information for Microsoft Configuration Manager current branch

This update is available in the **Updates and Servicing** node of the Configuration Manager console for environments running:

- Version 2603
- Versions 2503 and 2409 with the following update rollups installed:

  - KB [32851084](https://learn.microsoft.com/en-us/intune/configmgr/hotfix/2503/32851084): Update rollup for Microsoft Configuration Manager current branch, version 2503
  - KB [30385346](https://learn.microsoft.com/en-us/intune/configmgr/hotfix/2409/30385346): Update rollup for Microsoft Configuration Manager current branch, version 2409

### Restart information

This update doesn't require a computer restart or a [site reset](https://learn.microsoft.com/en-us/intune/configmgr/core/servers/manage/modify-your-infrastructure#bkmk_reset) after installation.
