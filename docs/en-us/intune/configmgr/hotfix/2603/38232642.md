# Security update for Microsoft Configuration Manager Console Extension

*Applies to: Configuration Manager \(current branch, version 2603, and versions 2509 and 2503 with update rollup installed\)*

Important

This update is superseded by [KB 39398030](https://learn.microsoft.com/en-us/intune/configmgr/hotfix/2603/39398030).

## Summary of KB38232642

An update is available that enhances security in Configuration Manager for importing console extensions. This update resolves the vulnerability described in [CVE-2026-47301](https://msrc.microsoft.com/update-guide/vulnerability/CVE-2026-47301).

Note

This same update is included with the second update rollup for Configuration Manager version 2509 \([KB 37864969](https://learn.microsoft.com/en-us/intune/configmgr/hotfix/2509/37864969)\). A separate out of band hotfix is not required for version 2509.

### Update information for Microsoft Configuration Manager current branch

This update is available in the Updates and Servicing node of the Configuration Manager console for version 2603 directly, and for version 2503 with the following update rollup installed:

- KB [32851084](https://learn.microsoft.com/en-us/intune/configmgr/hotfix/2503/32851084): Update rollup for Microsoft Configuration Manager current branch, version 2503

### Restart information

This update doesn't require a computer restart or a [site reset](https://learn.microsoft.com/en-us/intune/configmgr/core/servers/manage/modify-your-infrastructure#bkmk_reset) after installation.
