# ITSEnvClass Interface

The `ITSEnvClass` automation interface, in Configuration Manager, represents the operating system deployment task sequencing environment. This interface inherits from `IDispatch`.

## In This Section

| Term | Definition |
| --- | --- |
| [ITSEnvClass::Clear](https://learn.microsoft.com/en-us/intune/configmgr/develop/reference/core/clients/client-classes/itsenvclass--clear-method) | Clears an operating system deployment task sequence environment. |
| [ITSEnvClass::Create](https://learn.microsoft.com/en-us/intune/configmgr/develop/reference/core/clients/client-classes/itsenvclass--create-method) | Creates an operating system deployment task sequence environment. |
| [ITSEnvClass::GetVariables](https://learn.microsoft.com/en-us/intune/configmgr/develop/reference/core/clients/client-classes/itsenvclass--getvariables-method) | Gets the variables for the operating system deployment task sequence environment. |
| [ITSEnvClass::Value](https://learn.microsoft.com/en-us/intune/configmgr/develop/reference/core/clients/client-classes/itsenvclass--value-property) | Contains the value of an operating system deployment task sequence environment variable. |

## Remarks

The UUID for `ITSEnvClass` is 063B1AB6-598F-49D9-9B6D-68163476355F.
