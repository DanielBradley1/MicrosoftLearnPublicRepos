# Scheduling Client WMI Classes

The scheduling client Windows Management Instrumentation \(WMI\) classes, in Microsoft Configuration Manager, are used by client applications to manage scheduling on the client computer. They concern client-side behavior only.

## In This Section

| Term | Definition |
| --- | --- |
| [CCM\_Scheduler\_History Client WMI Class](https://learn.microsoft.com/en-us/intune/configmgr/develop/reference/core/clients/client-classes/ccm_scheduler_history-client-wmi-class) | Represents the history for a schedule. |
| [CCM\_Scheduler\_ScheduledMessage Client WMI Class](https://learn.microsoft.com/en-us/intune/configmgr/develop/reference/core/clients/client-classes/ccm_scheduler_scheduledmessage-client-wmi-class) | Represents the configuration of a scheduled message. |
