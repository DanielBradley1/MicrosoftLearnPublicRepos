# Application Management Client Interfaces

In Configuration Manager, the application management interfaces are used by client applications to manage application management functionality on the client.

## In This Section

| Term | Definition |
| --- | --- |
| [AppDetectState Enumeration](https://learn.microsoft.com/en-us/intune/configmgr/develop/reference/core/clients/client-classes/appdetectstate-enumeration) | The `AppDetectState` enumeration defines application installation states. This enumeration is used by the [IAppManagementHandler Interface](https://learn.microsoft.com/en-us/intune/configmgr/develop/reference/core/clients/client-classes/iappmanagementhandler-interface). |
| [AppContentInfo Structure](https://learn.microsoft.com/en-us/intune/configmgr/develop/reference/core/clients/client-classes/appcontentinfo-structure) | The `AppContentInfo` structure contains information about the application content. |
| [AppDeploymentTypeData Structure](https://learn.microsoft.com/en-us/intune/configmgr/develop/reference/core/clients/client-classes/appdeploymenttypedata-structure) | The `AppDeploymentTypeData` structure contains detection results for a set of deployment types. |
| [AppDeploymentTypeItem Structure](https://learn.microsoft.com/en-us/intune/configmgr/develop/reference/core/clients/client-classes/appdeploymenttypeitem-structure) | The `AppDeploymentTypeItem` structure contains detection results for an individual deployment type. |
| [IAppContentExt Interface](https://learn.microsoft.com/en-us/intune/configmgr/develop/reference/core/clients/client-classes/iappcontentext-interface) | The `IAppContentExt` interface defines functions to retrieve the application content information. |
| [IAppManagementHandler Interface](https://learn.microsoft.com/en-us/intune/configmgr/develop/reference/core/clients/client-classes/iappmanagementhandler-interface) | The `IAppManagementHandler` interface defines functions to interact with the handler. |
| [IAppManagementTypes Interface](https://learn.microsoft.com/en-us/intune/configmgr/develop/reference/core/clients/client-classes/iappmanagementtypes-interface) | The `IAppManagementTypes` interface is a container for Application Management related type definitions. |
