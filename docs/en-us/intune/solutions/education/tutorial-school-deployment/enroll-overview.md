# Device enrollment overview

![The device lifecycle for Intune-managed devices - enrollment](https://learn.microsoft.com/en-us/intune/solutions/education/tutorial-school-deployment/media/shared/enroll.png)

In this section you will:

- Enroll your devices into Intune

Select one of the following options to learn the next steps about the enrollment method you chose:

- [Automatic Intune enrollment via Microsoft Entra join](https://learn.microsoft.com/en-us/intune/solutions/education/tutorial-school-deployment/enroll-entra-join)
- [Automatic Intune enrollment with provisioning packages](https://learn.microsoft.com/en-us/intune/solutions/education/tutorial-school-deployment/enroll-package)
- [Automatic Intune enrollment with Windows Autopilot](https://learn.microsoft.com/en-us/intune/solutions/education/tutorial-school-deployment/enroll-autopilot)

- [Enroll with Company Portal](https://learn.microsoft.com/en-us/intune/solutions/education/tutorial-school-deployment/enroll-ios-company-portal)
- [Enroll devices with Automated Device Enrollment](https://learn.microsoft.com/en-us/intune/solutions/education/tutorial-school-deployment/enroll-ios-ade)
- [Enroll devices with Apple Configurator](https://learn.microsoft.com/en-us/intune/solutions/education/tutorial-school-deployment/enroll-ios-apple-configurator)

Tip

See [Plan enrollment](https://learn.microsoft.com/en-us/intune/solutions/education/tutorial-school-deployment/enrollment-planning) for a comparison between the enrollment methods which describes the ideal scenarios for using either option. It's recommended to review the table when planning your enrollment and deployment strategies.
