# Prerequisites and tasks to try and evaluate Microsoft Intune for free

You can evaluate and use Microsoft Intune with a free trial.

In this series of articles, you learn how to evaluate Microsoft Intune by stepping through common tasks, like adding users and groups, enrolling devices, creating policies, and adding apps. You can use a free trial to complete the steps in this series.

To learn more about Intune, see [What is Microsoft Intune?](https://learn.microsoft.com/en-us/intune/fundamentals/what-is-intune) and [Benefits of Microsoft Intune training path](https://learn.microsoft.com/en-us/training/modules/benefits-microsoft-endpoint-manager/).

## Recommended prerequisites

The following list includes recommended prerequisites when setting up Microsoft Intune:

- Use available devices on [supported operating systems](https://learn.microsoft.com/en-us/intune/fundamentals/ref-supported-platforms)
- Be familiar with [network endpoints for Microsoft Intune](https://learn.microsoft.com/en-us/intune/fundamentals/endpoints)
- Have an [app](https://learn.microsoft.com/en-us/intune/app-management/ref-protected-apps) that you can add to Intune, like a Microsoft 365 app
- Be familiar with [role-based access control \(RBAC\) in Intune](https://learn.microsoft.com/en-us/intune/fundamentals/role-based-access-control/overview)
